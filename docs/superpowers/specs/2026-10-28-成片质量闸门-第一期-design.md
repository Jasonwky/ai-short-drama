# 成片质量闸门 · 第一期(设计)

日期:2026-10-28 · 依据:`spike-results/2026-10-28-第1集成片问题根因.md` · 用户已定顺序:先 A + E + F1(本期)→ B + C → D(先对照实验)

## 目标

第 1 集暴露的 5 类问题(人物变样、没字幕、不明语音、服饰年代错、画风跳)在**任何一部剧**上都会再犯。
本期只做「代码规则就能拦住」的部分,让同样的坏东西**在出图 / 出视频之前就被拦下**,不靠人在成片里发现。

成功标准(可验证):
1. 角色有在途或缺失的四视图时,视频**规划不了**,就绪清单写明缺谁。
2. 首帧、视频、资产图、四视图的提示词里**都有**剧的画风与时代,由代码拼,LLM / 人写的部分不必记得写。
3. 资产表或段落提示词里出现本剧禁用词时,判卷 / 规划**拦下**并指出是哪个词。
4. 没有台词的段落,视频提示词里**没有任何人的声音描述**,并写明「全程没有人说话」。
5. 每一段(含无台词段)当前视频都要过一次语音检查;台词之外多说 ≥ 3 个字 → **拦导出**。
6. 旁白在成片里**以字幕出现**(不配音)。
7. 「成片」面板能一键出**整集预览**(烧好字幕),不必等看片确认。
8. 每张资产图(正面图、四视图、场景空镜、道具图)出来后**先由 AI 按固定维度逐项检查,再由人定稿**;
   没定稿的资产图不能用来出首帧 / 视频。这一步在全剧流程里自动排、自动跟进(用户 2026-10-28 加)。

不在本期:首帧的视觉检查闸门(C)、一段一镜(D)、旁白配音(F2)。

## 1. 四视图闸门(问题 1 的直接根因)

- `planner.video_problems` 加两条:
  - 本段绑定的角色里,有**四视图任务在途**(`kind='image'`、写 `fourview_path`、状态未结束)→「角色「X」的四视图还在生成,等它出完再规划视频」;
  - 本段**有台词**的角色缺四视图 → 「角色「X」还没有四视图」。不说话的角色(群演、背影)缺四视图不拦,只在就绪清单提示。
- 增量补全(`gen/fill.py`)与全剧流程(`flow.plan_media`)自然跟着拦:它们都走 `*_problems`。
- 槽位只有 2 张四视图(`H3_IMAGE_SLOTS - 1`),按台词多少分,这条规则不变。

## 2. 剧级美术设定(问题 4、5)

### 数据

- 库结构 v23:`drama.art_json`(TEXT,默认 `''`),内容 `{"era": str, "costume": str, "banned": [str]}`:
  - `era` 时代 / 世界观一句话(例:「架空古代,类北宋边军」);
  - `costume` 服饰总则(例:「交领右衽、粗布或皮甲,无纽扣、无口袋、无翻领」);
  - `banned` 禁用词(中英都可,例:`uniform`、`pocket`、`button`、`jacket`、`衬衫`、`口袋`)。
- 画风沿用已有的 `drama.style`(`styles.STYLES`)。`Style` 加一个中文字段 `zh`(视频提示词用,H3 吃中文):
  写实 =「写实真人实拍,电影质感,不要动画、卡通、3D 渲染」。

### 注入(全部由代码拼,写在提示词末尾)

| 提示词 | 拼什么 | 位置 |
|---|---|---|
| 资产图 `assets.asset_prompt` | 已有 style prefix / avoid;**加** `Setting: {era}. Costume: {costume}.`(角色)/ `Setting: {era}.`(场景、道具) | `final_prompt` 之后 |
| 四视图 `FOURVIEW` | 同上 | `{desc}` 之后 |
| 首帧 / 尾帧 / 关键帧 `planner._plan_image` | **新增** style prefix + `Setting: {era}.`,结尾 `Avoid: {style.avoid}.` | `tags.expand` 之后 |
| 视频 `planner.plan_video` | **新增**「画面风格:{style.zh}。时代:{era}。」 | 运镜之后 |

- `art_json` 为空的剧:时代那半句不拼;画风照拼(画风是必填的,原来就有)。
- 任务参数里记 `art`(当时的设定快照),溯源与「设定改过、当前图还是旧设定」提示用。

### 禁用词

- `cast` 判卷:任何 `final_prompt` / 造型字段含禁用词 → 回炉,错误写明「角色「孙老栓」的 final_prompt 含禁用词 uniform」。
- `assets.asset_problems`、`planner._image_problems`、`video_problems`:人手改出来的禁用词同样拦。
- 匹配:英文按整词、不分大小写(`\buniform\b`);中文按子串。
- `cast` 的 `<context>` 带上 `<art>`(era / costume / banned),让 LLM 一开始就照着写。

### 控制台

- 「逐集」面板全剧流程栏的 ②「AI 出资产表」前加一格「美术设定」:三个输入框,保存即写 `art_json`。
- **待定但不可跳过**:`era` 为空时 ② 不能跑(flow 显示「先填美术设定」,手动跑也拒绝)。已有资产表的剧不追溯拦。

## 3. 声音规则 + 全段语音检查(问题 3)

### 视频提示词

- `voices` 只写**本段有台词的角色**(现在是本段所有角色)。
- 本段没有台词:不写任何声音,改写「全程没有人说话,只有环境声。」
- 台本快照 `script.voices` 跟着变(只记写进去的)。

### 对齐扩到无台词段

- `gen/align.align_problems` 不再拒绝无台词段;`lines = []`。
- `aligner.run`:`lines` 为空时不出字幕(`writes` 记 `none`,结果是 `align.json`),判卷改为「识别到 ≥ 3 个**有能量支撑**的字 → 失败:无台词段出现人声「…」」(复用 `extra_speech` 的能量判据,whisper 在静音上编字不算)。
- 有台词段:现有判卷之外,`extra_speech` 有 runs → 对齐**仍出字幕**,但结果里记 `extra`。

### 导出拦

- `export.readiness` 加:每段当前视频都要有一条 `done` 的对齐(`params.video` = 当前视频),否则「段落 N 还没做语音检查」;
  有多说 → 「段落 N 台词之外多说了「…」(第 x–y 秒)—— 重出视频」。
- 全剧流程:`flow.advance` 在视频出完后**自动排对齐**(同一条视频只排一次,失败不重试,沿用防空转规则)。

## 4. 旁白出字幕(问题 2 的真缺口,F1)

- `rules.narration(description) -> list[str]`(已有 `_NARRATION` 正则)。
- 字幕合成 `export._parts`:每段在对齐出的台词字幕之外,按顺序加入旁白条:
  - 时长 = 字数 × 0.25 秒,夹在 [1.5, 段长] 秒;
  - 放在本段**没有台词字幕的最长空档**里,空档放不下 → `readiness` 报「段落 N 的旁白放不下(空档 x 秒,要 y 秒)」;
  - 和台词字幕同样经 `fit_screen` 拆行;读回自检(第 8 项)用同一份合成结果,不另算。
- 视频面板的字幕预览也显示旁白条(标「旁白」)。

## 5. 整集预览

- 「成片」面板加「预览整集」:后台把当前各段视频拼起来,烧上台词 + 旁白字幕,写 `outputs/preview/episode-<id>.mp4`,面板里直接播。
- 不过任何导出闸门(看片确认、烧字检测等都不查),不加显式标识与元数据,页面上标明「预览,不是成片」。
- 复用 `media.encode_episode`;预览覆盖写,不进溯源。

## 6. 资产图 AI 检查 + 人工定稿(B,用户要求并入本期)

现状:资产图**没有定稿这一步** —— 第一张出来就写进资产,直接被首帧 / 视频拿去当参考,孙老栓的近代制服、
燕无咎的黑烟就是这样一路进了成片。

### 6.1 定稿(数据)

- 库结构 v23 新表 `asset_approval`:`(table_name, row_id, slot, sha256, verdict, reason, check_run, decided_at)`,
  `slot ∈ {image, fourview}`,`verdict ∈ {approved}`,写下不可改(触发器)。
- **只认那张图的 sha256**:换了图(重出后在历史里调用、上传)定稿自动失效,要重新审。
- 闸门:
  - 首帧 / 尾帧 / 关键帧规划:本段绑定的角色正面图、场景空镜、道具图都要**已定稿**;
  - 视频规划:进参考槽的四视图要已定稿(与第 1 节四视图闸门合在一起);
  - 四视图规划:正面图要已定稿(四视图以它为输入,正面图不对,四视图白出)。
- 老剧:本期上线时**不自动追认**已有的图(题甲两部剧都要过一遍检查),就绪清单写「资产图未定稿」。

### 6.2 代码先查(能确定性测的不交给 LLM)

在 AI 检查之前由代码出结论,结果和 AI 的一起显示:

| 检查 | 适用 | 判法 |
|---|---|---|
| 尺寸 / 画幅 | 全部 | 与 `SPEC` / `FOURVIEW_SIZE` 一致 |
| 白底 | 角色正面、四视图、道具 | 四条边各 8 像素宽的带子里,接近白(亮度 ≥ 235、饱和度低)的像素 ≥ 90% |
| 四宫格 | 四视图 | 竖向 4 等分,每格都有非白的人形区域(列投影),相邻格之间有白缝 |

阈值用题甲已有的 57 张资产图标定(按 CLAUDE.md 落 spike 文档),不拍脑袋。

### 6.3 AI 检查(LLM 任务 `asset_check`,视觉)

- 目标:一个资产的一个槽位(`character` 正面 / 四视图、`scene`、`prop`),参数记图的 sha256。
- 输入:这张图(角色的四视图检查同时给正面图,横拼),图底印校验数字;资产的文字描述(外貌、造型、地点、时间、光线、陈设、道具描述)、
  剧的画风与美术设定(第 2 节),都作为 `<asset>` / `<art>` 数据,不是指令。
- 输出(闭集,schema 严格):每个维度一条 `{dim, verdict: 通过|不通过|看不出, evidence, fix: 无|重出|改描述, suggestion}`,
  **维度必须一个不落**(代码判卷:缺维度、重复维度、「不通过」没写 evidence、校验数字读错 → 回炉)。
- 维度(按槽位):

  | 维度 | 正面图 | 四视图 | 场景 | 道具 |
  |---|---|---|---|---|
  | 时代与服饰(对美术设定,含禁用物件:口袋、纽扣、翻领…) | ✓ | ✓ | ✓ | ✓ |
  | 画风(写实 / 二次元…是否一致,有无卡通、3D 渲染感) | ✓ | ✓ | ✓ | ✓ |
  | 与描述一致(年龄、性别、发型胡须、体型、服装、手持物;场景的时间光线陈设;道具形制) | ✓ | ✓ | ✓ | ✓ |
  | 构图规范(单人全身正面 / 四个方向顺序对 / 无人空镜 / 单件居中) | ✓ | ✓ | ✓ | ✓ |
  | 瑕疵(烟雾、多余肢体、畸形手、文字水印、裁切、杂物) | ✓ | ✓ | ✓ | ✓ |
  | 与正面图同一人(脸、发型、服装、鞋) | | ✓ | | |

- **全剧对照**(同一任务,参数 `scope=drama`):所有角色正面图拼一张、所有场景空镜拼一张(每格下印名字和编号),
  维度闭集:「画风统一」「角色撞脸(两个不同角色看起来像同一人)」「时代统一」;每条问题必须指出格子编号,代码核编号存在。
  在⑤里所有单张都检查完后自动排一次;有问题挂在相关资产的卡上。
- **只提示不拦**:这是模型判模型,准不准没标定;拦不拦由人定稿决定(见 6.4)。
- 不写回任何字段;结果留在 `llm_run`,定稿页只认「这张图」的那次。

### 6.4 人工定稿(审阅页)

- 入口:全剧流程栏新增一格「⑤ 资产图审」(在「出图 / 声音」之后),点进 `/drama/{id}/asset-review`;资产面板每张图旁也有入口。
- 页面:每个资产一张卡 —— 图(正面 + 四视图)、代码检查结果、AI 逐维度结论(不通过的标红、写证据和建议)。
- 人对每张图三选一:
  - **定稿**:AI 和代码都通过 → 直接定稿;有不通过项 → **必须写理由**才能定稿(理由进 `asset_approval.reason`);
  - **重出**:换种子重出一张(进历史),新图出来后流程自动再检查,回到这张卡;
  - **改描述再重出**:编辑生成描述(带上 AI 的建议文字,人可改),保存后重出。
- 「全部通过的一键定稿」:只作用于代码 + AI 全部通过的图。
- 已定稿的卡回显:谁定的、何时、理由、当时的 AI 结论。

### 6.5 进流程

- `flow.status` 新增「⑤ 资产图审」:`blocked`(还有图没出完)→ `checking`(AI 检查在排 / 在跑)→ `waiting`(等人定稿 N 张)→ `done`。
- `flow.advance`:每张资产图出来后自动排一次 `asset_check`(同一张图 sha 只排一次,失败不重试 —— 沿用防空转规则);
  人点「重出」后新图同样自动检查。
- 「逐集分镜」不等⑤(分镜只用资产文字);首帧 / 视频由 6.1 的闸门拦住,流程栏显示「等资产图定稿」。

## 测试

- 单测:四视图在途 / 缺失拦规划;四类提示词都含画风与时代、`art_json` 为空时视频提示词只多画风;禁用词在 cast 判卷、资产、段落三处拦;
  无台词段提示词无声音描述;无台词段对齐判卷(有能量的字 → 失败,无能量的编字 → 通过);导出缺语音检查 / 多说拦;
  旁白放进空档、放不下报错、读回自检含旁白;预览路由;
  定稿只认 sha(换图失效)、未定稿拦首帧 / 视频 / 四视图规划、有不通过项定稿必须带理由、定稿不可改;
  `asset_check` 判卷(缺维度、校验数字错、不通过无证据 → 回炉);白底 / 四宫格代码检查;流程⑤各状态与自动排检查。
- 真 LLM 契约:`cast` 带 `<art>` 时不写禁用词;`asset_check` 对孙老栓现有四视图(近代制服)判出「时代与服饰 不通过」,
  对燕无咎正面图判出「瑕疵 不通过」(烟雾)—— 用题甲真实图当黄金样本。
- 迁移:v22 → v23(`art_json` + `asset_approval`)。
- Playwright 有头全面自测 + 新元素判据(美术设定输入框、资产图审页、预览按钮)。
