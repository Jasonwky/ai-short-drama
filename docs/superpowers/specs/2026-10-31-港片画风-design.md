# 港片画风(90 年代港产武侠片)设计

> 状态:**待用户批准**。用户 2026-10-31:「定下港片风格」。依据:spike-results/2026-10-31-降低AI感调研.md 第 1、6、7、9 节
> (参考视频两条;同种子对照:提示词 + 后期调色有效,写「胶片 / 年代」词本身不够;港片定妆图 / 搭景场景图明显更像真人;H3 官方结构化提示词让镜头顺序听话)。

## 1. 做法:加一个画风预设,不改别的剧

`drama/styles.py` 现有 写实 / 二次元 / 半写实 3D 三个预设。新增 **`hk90`「90 年代港产武侠片」**,题甲切到它;其它剧不受影响。
`Style` 加两个字段:`video_en`(视频英文风格开场句,H3 指南要求)与 `grade`(导出调色预设名,其它预设为空 = 不调色)。

| 用在哪 | `hk90` 写什么(实验里验证过的写法) |
|---|---|
| 资产正面图 `prefix` | film still photograph of an actor in costume from a 1990s Hong Kong wuxia film; ordinary face with slightly uneven features, weathered skin with visible pores, real soot / dirt; thick handmade, worn, patched costume; 1990s Hong Kong film makeup and styling; 35mm film grain |
| 场景图 `prefix` | film still from a 1990s Hong Kong wuxia film: built studio set, layered background fading into dry-ice fog, cold blue-cyan haze backlight, warm practical firelight / lantern light, soft diffusion bloom, telephoto compression, 35mm film, faded print |
| 首帧 / 尾帧 / 关键帧后缀 | 同场景那套光线词 + 「a subtle thin rim light」(实验里逆光写重了像头发着火)+ ordinary imperfect face, real soot;**不写** photorealistic / cinematic;否定词不放正向 |
| 负向提示词(新,CFG > 1 的资产图才生效) | Qwen 官方负向原文 + 网红脸、磨皮、塑料皮肤、动画、卡通、3D 渲染 |
| 视频 `video_en` | The target video is in realistic photographic style, like a still from a 1990s Hong Kong wuxia film: built studio set, dry-ice haze, cold blue-cyan backlight against warm firelight on the faces, soft diffusion bloom, telephoto lens, 35mm film grain. |
| 导出 `grade` | `hk90`:实验调色链 `tmp/realism_ab/wxgrade.sh` 固化为参数(泛光、青蓝暗部 / 暖橙高光、抬黑、降一档清晰度、颗粒 20、暗角) |

视频侧:现在的中文 `video_phrase`(含「电影质感」与否定句)在 `hk90` 下换成 `video_en` 放在提示词**最前**;台词照旧不写进提示词(钉音频)。
本期**不**改成 H3 六段全英文结构(那是「H3 自己出声」方案的一部分,用户已选 TTS 钉音频路线)。

## 2. 调色只在导出最后一步

- `cut/export.run`:各项检测(白屏、烧字幕、切镜、口型、读回自检)照旧对**原片**跑;出带 / 不带标识两版之前,按剧的 `grade` 逐段套 ffmpeg 调色。
  理由:颗粒会让 `blankscan` 的「无纹理平底」漏检,且改 sha256 会让各类缓存失效(调研 §2、§6)。
- 读回自检加一项「调色已套用」(带 / 不带标识两版都查:与原片的饱和度 / 暗角差在预期范围,阈值标定后写进 spike)。
- 溯源报告 / 导出快照记录 `grade` 名称与参数(不可改)。
- 视频卡片与「成片」整集预览加「港片调色预览」开关(只在浏览器端出预览文件,不改库里视频)。

## 3. 资产与已有产物

- 切画风**不作废**任何已生成的图 / 视频(用户一贯原则);首帧卡片照旧提示「当前首帧是旧画风」(首帧任务已记 `frame` 快照,加记 style key)。
- 第 1 集的三个主角(燕无咎、霍猛、孙老栓)与第 1 集用到的场景(校场、伙房、营地空地、伙房后院)按新画风**重出正面图 / 场景图 → 人定稿 → 重出四视图 → 首帧 → 视频**。
  定稿走现有「资产图审」(浅色底检查:港片定妆图用浅灰棚拍底,实验里过得了代码查,上线时再核)。

## 4. 测试

- 单测:`styles.get("hk90")` 字段齐;`frame_suffix` / `video_phrase` 在 hk90 下的产出(英文开场在最前、不含「电影质感」与否定句);
  导出调色:检测吃原片、成片吃调色版;读回自检新项;溯源记录 grade。
- Playwright 有头自测:立项页可选「90 年代港产武侠片」;视频卡片预览开关。
- 真机:第 1 集第 2 段按新资产重出首帧与视频,人看。

## 5. 与配音方案的关系

- 配音换 IndexTTS2(spec 2026-10-31-IndexTTS2港片配音-design.md)与本画风互相独立,可以分开实施;第 1 集两者都换后再统一重出视频,省一轮云机时间。

## 6. 自查补充(2026-10-31,对照代码核过)

| # | 漏洞 | 修正 |
|---|---|---|
| G1 | `Style.prefix` 只有一条,资产 / 场景 / 道具 / 首帧共用;港片的人、景、物写法完全不同 | `hk90` 按用途分:`asset_prefix[character / scene / prop]`、`frame_look`;其它预设不填则回落到原 `prefix`,行为逐字节不变 |
| G2 | 第 1 节把「冷蓝逆光 + 暖色火光」写死,**白天戏(校场、营地空地)也会变成夜景火光** | 画风只给**质感词**(胶片、颗粒、长焦、柔光、妆发、戏服做旧、搭景);光线按场景自己的 `time` / `lighting` 字段选:夜 / 黄昏 / 室内火光 → 冷蓝雾 + 暖火光;白天 → 强日光穿尘雾 + 偏暖褪色;`video_en` 同样分两版 |
| G3 | `workflows.build_qwen` 没有负向提示词参数(节点 22 恒为空串) | 加 `negative=`;只有 CFG > 1 才生效 —— 资产正面图(baseline,CFG 4)有效,首帧 / 四视图(Lightning,CFG 1)**无效**,文档与面板如实标注 |
| G4 | 角色定妆图要过「资产图审」的代码查(浅色底、没被裁切、四视图四格);港片写法加了颗粒 / 侧光 / 灰底,可能过不了 | 角色 / 道具前缀**不写**颗粒和光线,背景沿用 `SPEC` 的纯白棚拍底;上线前拿 3 张实测过 `assetscan`,结果记进 spike |
| G5 | 导出是 `media.encode_episode` **一遍**里烧字幕 + 显式标识;调色若加在它之后会把字幕和「AI 生成」标识也弄糊,读回自检的字幕 OCR / 标识比对可能误判 | 调色**逐段先做**(只对画面,音频原样),再交给 `encode_episode` 烧字幕与标识;检测仍对原片 |
| G6 | `drama.style` 不在 `repo` 字段白名单里 —— 建剧后改不了画风 | 白名单加 `style`(画幅仍不可改);改画风写 journal;首帧任务快照记 style key,卡片据此提示「旧画风」 |
| G7 | 港片布光偏暗、火光照脸,口型检查(mediapipe)「无法判定」可能变多 | 真机验收时统计第 1 集「无法判定」占比,超过一半就回头调首帧提示词(脸部受光) |
| G8 | 参考片是宽银幕横屏,我们是 9:16 竖屏;「长焦压缩」在竖屏近景里效果不同 | 不加黑边;竖屏照旧按 `framing` 规则定景别,只借质感 |
