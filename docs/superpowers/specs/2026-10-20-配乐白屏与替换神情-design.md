## 一、配乐混音

### 为什么现在能做

总设计「四路提示词」里有 BGM / 音效,当时砍掉的理由是「AI 生成配乐要开卡」且 **MusicGen 权重 CC-BY-NC**(许可证红线)。
这次**不做 AI 生成**:人上传一首**有许可的**音乐文件,导出时本机混进成片。

### 数据

- 新表 `music_cue`(库结构 v10 → v11,带迁移):`id` · `episode_id` · `path`(相对 data_root,`assets/music/<sha 前 16 位><扩展名>`)·
  `sha256` · `license`(**★必填**:来源与许可说明,空串拒绝)· `start_sec` / `end_sec`(成片时间轴上的起止,秒)·
  `gain_db`(音乐本身音量,默认 -14)· `duck_db`(台词期间再压低多少,默认 -10)· `fade_in` / `fade_out`(秒,默认 1.0)· `created_at`
- 写入走 `repo` 字段白名单;删除一条 cue 不删文件(同一文件可被多条引用)
- 工程包:导出 / 导入带上音乐文件,路径重映射、逐文件 sha256 校验(与素材同一套)

### 面板(成片)

- 上传音乐(mp3 / wav / m4a / flac / ogg;ffprobe 读不出音轨 → 400 说原因)+ 许可说明
- 每条 cue 一张卡:起止、音量、压低量、淡入淡出 —— 数字可改;**音量曲线**(SVG):横轴成片时间,画出这条音乐的实际增益,台词区间打底色
  (台词区间来自各段已对齐字幕的起止 + 段落在成片里的偏移)
- **试听**:本机 ffmpeg 只混音频(不重编码视频)出一段 m4a,`<audio>` 播放;试听文件进 `outputs/preview/`,不入库
- 轻量检查(导出前):cue 终点超出成片时长、文件丢失 / 哈希对不上、license 为空 → 列在导出检查里,不过不许导出

### 混音

- 纯函数 `cut/music.py`:由 cue + 台词区间算增益包络(台词前后各 0.3 秒过渡),生成 ffmpeg 滤镜表达式;单测覆盖包络
- 导出 `run`:两版(带 / 不带显式标识)都混入;原视频音轨(对白)不衰减,音乐按包络叠加
- **读回自检加一项「配乐」**(8 → 9 项):对**成片文件**实测 —— 在每条 cue 的非台词区间里,成片音频与「不混音乐的原音轨」的差异能量明显大于 0(音乐在);
  在所有 cue 之外的区间,差异 ≈ 0(没有漏混)。没有 cue 时此项 PASS 并写明「本集无配乐」
- 溯源报告列出每条配乐:文件、sha256、license、起止 —— 标明「人工提供,非 AI 生成」

## 二、白屏检测

- 实战第 2 段第三轮视频中段约 3 秒纯白(疑似四视图白底带进视频,未核实)
- `cut/blankscan.py`:ffmpeg 找「连续 ≥ 0.5 秒、画面近乎纯白」的区间(阈值用实战片子标定,写进调研落档:命中那条要报出来、其余实战视频零误报);
  结果按视频 sha256 缓存在 `<视频>.blankscan.json`(与 `textscan` 同一做法)
- 导出 `run` 开工前逐段检查,命中 → `CutError`「段落 N 第 a–b 秒画面近乎全白,重出这段再导」;`readiness` 只读缓存
- 视频面板:卡片上读缓存,命中就提示(没查过的不在渲染时现算,避免页面卡)
- 单测用 ffmpeg lavfi 现造小视频(纯白段 / 白墙但有内容 / 正常画面);ffmpeg 不在时跳过并写明原因

## 三、局部替换自动带神情

- 依据:`spike-results/2026-10-20-P15两遍合成与局部替换云机实测.md` —— 默认提示词会抹平神情;补充说明手写神情 3/3
- 纯函数:从这一格的图提示词里,取 `@名字` 到下一个 `@` 之前的文字,去掉开头的 `@名字`、去掉首尾分隔符,作为该角色的默认补充说明
  (例:第 5 段 `@李福 头戴黑色幞头、身穿深褐色长袍,脸色煞白跪倒在地,惊恐地抬头,背后能看到…` → `头戴黑色幞头、身穿深褐色长袍,脸色煞白跪倒在地,惊恐地抬头,背后能看到…`)
- 只对角色;下拉选角色时填入补充说明框(人改过就不再覆盖);场景 / 道具不填
- 效果要下次开卡验证(记真剩项)
