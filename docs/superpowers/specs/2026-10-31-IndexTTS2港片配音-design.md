# 台词配音换 IndexTTS2(港片配音念法)设计

> 状态:**待用户批准**。依据:spike-results/2026-10-31-降低AI感调研.md 第 8–12 节(同一句台词逐字对比,用户选定「① ×1.4 快版」)。
> 用户决定(2026-10-31):① 念法模板用我们自己合成的音频(方案 A);② 新角色音色设计仍用 Qwen3 VoiceDesign,**眼下不装**(硬盘不够),先用 IndexTTS2 把第 1 集做完。

## 1. 目标与边界

- 目标:台词音频从「Qwen3-TTS Base 逐句克隆」换成「IndexTTS2 克隆音色 + 念法模板引导 + 连着说 + 音高起伏放大」,让声音接近参考片的港片国语配音念法。
- 不变:视频钉台词音频(`build_h3(guide_audio=)`)、逐句回听判卷(拼音)、口型闸门(逐句时段来自台词音频的 spans)、导出闸门、`tts.stale` 的过期判断思路。
- 不做:角色音色设计(`voice` 任务,Qwen3 VoiceDesign)这条链路代码不动;云机上模型不在时,它照旧按「模型目录不在」退出码 2 **报错失败**(不静默)。
- 不做:情绪按句自动判断(LLM 打标签)—— 第一期每个角色一个默认念法模板,够第 1 集用;以后再加逐句覆盖。

## 2. 配方(实测选定,参数进能力声明,不在代码里散落)

每句台词:
1. 文本:去掉句内的逗号 / 顿号 / 分号(句末 `。!?` 保留),让模型连着念;
2. `IndexTTS2.infer(spk_audio_prompt=说话人定稿试听音, emo_audio_prompt=该角色的念法模板, emo_alpha=1.0, interval_silence=0)`;
3. 后期:剪掉超过 0.06 秒的静音(阈值 −38 dB);WORLD(pyworld)把对数音高围绕中位数放大 **1.4 倍**,不改时长;
4. 句与句之间留 `GAP_SEC`(由 0.4 改为 0.15 秒,连贯),开头 / 结尾留白不变;spans 照旧按拼接位置算。

`capability.INDEX_TTS2`:python(`/root/autodl-tmp/indextts/venv/bin/python`)、repo 目录、checkpoints 目录、`emo_alpha`、`pitch_widen=1.4`、`squeeze_gap=0.06`、`vram_gb`(上线前实测填)。

## 3. 念法模板(新)

- 是什么:一段几秒的音频,只当「怎么念」的参考(IndexTTS2 的 `emo_audio_prompt`),不当音色。
- 存哪:每部剧一张小表 `voice_template`(库结构 v26):`id, drama_id, name(如「喝令」「惊疑」「低声狡黠」「平述」), path, sha256, note, created_at`;
  角色加一列 `voice_template_id`(该角色台词默认用哪个模板)。
- 怎么来(方案 A):
  - 「喝令」:直接用本次实验选定的那条(`tmp/idx/l2_emoref_sq_w14.wav`,霍猛音色)导入;
  - 其余:在「资产图审 → 角色声音」区新增「念法模板」小节:写名称 + 选一种情绪向量预设 → 云机用 IndexTTS2 合成 3 个候选(同样过去停顿 + ×1.4)→ 人听了挑一个存为模板。
  - 合规:模板只能来自我们自己合成或自己录制的音频;面板上传入口写明「不得用他人作品里的声音」。参考视频原声只做测量,不进库。
- 定稿:模板不走 `asset_approval`(它不是交付画面 / 音色,只是生成参数);改了模板 = 用它的角色的台词音频过期(第 5 节)。

## 4. 执行(云机)

- 新脚本 `serve/idx_remote.py`(顶层只用标准库,`main()` 里才 import torch / indextts / pyworld),接口与 `tts_remote.py` 对齐:
  `<venv python> - <checkpoints 目录> <任务 JSON>` → stdout 最后一行 `{"wav_b64","sr","sec","spans","gen_sec"}`;退出码 2 = 文件不在,3 = 显存不够(走现有 `aligner.oom_wait`)。
  内含两处兼容垫片(实测必需):`torchaudio.save` → soundfile;HF 走 hf-mirror。
- `serve/ttser.py`:按任务参数 `workflow` 分派 —— `qwen3_tts_clone`(旧任务,只读兼容)/ `indextts2_hk`(新);重试换种子、逐句拼音回听判卷、写 `tts.json` 全部沿用。
  回听判卷注意:去掉逗号后 Whisper 仍按字比拼音,不受影响(实测「这不是我的身子这是哪儿」逐字对上)。
- 共用机纪律不变:ComfyUI 队列有任务 → pending;OOM → pending 等下个空档。

## 5. 规划与过期

- `gen/tts.plan_tts`:参数快照加 `engine="indextts2_hk"`、每个说话人的 `template: {id, path, sha256}`、配方参数(emo_alpha / pitch_widen / squeeze_gap / gap)。
- `tts_problems` 新增:说话人没设念法模板 → 「到资产图审给『X』选念法模板」。
- `tts.stale` 新增:说话人的模板换了 / 模板文件 sha 变了 / 配方参数变了 → 过期(视频规划照旧据此拦)。
- 第 1 集已有的 Qwen3 台词音频:规则上全部视为「配方变了」→ 过期,需要重合成、视频重出(用户已知)。

## 6. 面板

- 「资产图审 → 角色声音」:每个角色多一个下拉「念法模板」;新增「念法模板」小节(列表 + 试听 + 生成候选 + 存为模板 + 导入本地 wav)。
- 视频面板「台词音频」块:显示引擎 + 每句用的模板名;其余不变。
- Playwright 自测补:选模板、生成候选(假后端)、台词音频过期提示。

## 7. 测试

- 单测:`idx_remote` 参数检查;`plan_tts` 快照含模板与配方;`stale` 三种过期;`ttser` 按 workflow 分派、OOM → pending;库迁移 v26(`_drop_v26`)。
- 假后端:`FakeTts` 支持新 workflow(同样回 spans)。
- 真机验收:第 1 集第 2 段 → 台词音频(回听过)→ 钉进 H3 → 口型闸门;人听。

## 8. 风险

- 去掉逗号后长句可能一口气太长、模型吞字 —— 回听判卷兜住,不过就换种子;仍不过的句子在面板提示「拆句」。
- ×1.4 放大对女声 / 高音角色可能刺耳 —— `pitch_widen` 先全局,后续可按角色覆盖。
- IndexTTS2 许可(bilibili Model Use License):月活 1 亿 / 年营收 10 亿以上须另签;须保留声明与协议副本 —— 交付物溯源报告里写明配音模型与许可。
- 云机硬盘:IndexTTS2 共约 10 GB 常驻;VoiceDesign 需要时临时装、用完删(用户 2026-10-31 定)。
