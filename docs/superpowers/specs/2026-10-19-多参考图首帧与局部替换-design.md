# 多参考图首帧(两遍合成)与框选局部替换 · 设计

- **日期**:2026-10-19
- **依据**:`spike-results/2026-10-19-首帧多参考图实测.md`(Qwen 编辑模型只有 3 个图槽;3 角色 + 1 场景时现状 0/3 认对人,整图两遍 3/3)、
  `spike-results/2026-10-19-多角色同框常规做法调研.md`(业界主流是「先出整体构图,再逐人局部重绘」)
- **用户定**(2026-10-19):分镜**不限**每段角色数;两件都做 —— ① 参考图超过 3 张时**自动整图两遍合成**,第二遍「换脸换装」由代码生成提示词;
  ② **人工框选局部替换**(不做自动人物识别)

## 目标

1. 一段的参考帧(首帧 / 尾帧 / 关键帧)要用的参考图超过 3 张时,自动两遍合成,放不下的角色也按定妆图出图;3 张以内行为与现在**逐字节相同**
2. 任何一张已有的参考帧,人可以在图上框一块、选一个本段绑定的素材,生成「只有框内变成这个素材」的新版本,框外像素不动

## 不做

- 三遍及以上(两遍最多 5 张参考图;再多的照旧退化成名字并警告)
- 自动找人 / 人脸比对(云机共用不装节点;本机做要拆三段任务 —— 用户定人工框选)
- 视频(H3)四视图槽位;编辑页新字段;分镜 LLM 改动

---

## 一、整图两遍合成(自动)

### 分槽

沿用 `refs.allocate_slots` 的优先级(台词最多的角色 > 场景 > 第二个角色 > 道具 > 其余角色),排好序后切两份:

- **第一遍**:前 3 张。提示词按原图提示词展开,没进第一遍的素材**退化成名字**(就是现状:站位、动作按原提示词来)
- **第二遍**:第 4、5 张。`Picture 1` = 第一遍出的图,`Picture 2 / 3` = 这两张参考图
- 第 6 张起照旧出槽,记进 `dropped`,就绪清单照旧警告

### 第二遍提示词(代码生成)

每张第二遍参考图一句:角色 —— `把画面中的{名}换成 Picture {k}({名}) 的长相、发型发饰和服装`;场景 / 道具 —— `把画面中的{名}换成 Picture {k}({名}) 的样子`。
整句:`保持 Picture 1 的画面、构图、光线、动作和其他人物完全不变,只做以下修改:{逐句,分号隔开}。` 生成后过 `tags.check_tags`(3 张都要被引用)。

### 任务与工作流

- **一个任务、一个 ComfyUI 工作流、一张图**:第二遍串在同一份工作流末尾。状态机、写回、挑版本、改参重跑、溯源、工程包不用改
- 任务参数加 `second_pass = {"image_refs": [路径…], "names": [名…], "prompt": "…"}`;没有第二遍时**不写这个键**
- 任务 `refs` = 第一遍 + 第二遍全部参考图 —— 上传、工程包重映射、溯源按它走
- `planner._plan_image` 算分槽、生成第二遍提示词;`workflows.build_qwen(…, second_pass=(提示词, [图名…]) | None)` 串出
  第二个 `TextEncodeQwenImageEditPlus`(image1 = 第一遍 `VAEDecode` 输出)→ `FluxKontextMultiReferenceLatentMethod` → `KSampler` → `VAEDecode` → 原 `SaveImage`。
  第二个采样器**复用第一遍的步数 / CFG / 模型 / 负面条件节点**(模板预设改步数两遍一起生效),种子 = 原种子 + 1
- `dispatch.build_workflow` 读 `second_pass`,路径换成上传名后传给 `build_qwen`

### 界面与估时

- 参考帧面板就绪清单:有第二遍时一条 warn `多参考图 {N} 张:两遍合成,耗时约 2 倍(第二遍换成定妆图:{名…})`;
  被第二遍兜住的素材**不再**出现在「因槽位不足仅以文字描述参与」里
- 估时:补全确认页与作废代价里,两遍的参考帧按 2 张图算(`planner.frame_passes(store, segment_id) -> 1 | 2`)

## 二、框选局部替换(人工)

### 交互

参考帧面板每张**已有图**的首帧 / 尾帧 / 关键帧卡片上加「局部替换」:

1. 在图上拖一个框(浏览器里按图片原始像素换算;框会对齐到 16 的倍数、四周各外扩 32 像素作羽化余量,夹在图内)
2. 下拉选一个本段绑定的角色 / 场景 / 道具(只列有参考图的)
3. 可选一句补充说明(默认空)
4. 种子 → 「生成替换版」

### 任务

- 新任务与该帧的普通生成同一个写回位置(`writes` / `keyframe_id` 照旧经 `drama/targets.slot`)—— **新版本进历史等人挑**(写回只填空位,与现有规则一致),
  点「用这一版」才替换当前帧,照常让视频作废
- 参数:`workflow = "qwen_region"`,`source`(被改的那张图的路径,即当前帧)、`box = [x, y, w, h]`、`ref`(素材参考图路径)、`ref_name`、`note`
- 提示词(代码生成):`保持 Picture 1 的构图、姿态、动作、光线和背景不变,把其中的人物换成 Picture 2({名}) 的长相、发型发饰和服装。{补充}`
  (场景 / 道具用「…换成 Picture 2({名}) 的样子」)
- `refs` = [source, ref]

### 工作流(全是核心节点 + 现有 Qwen 节点)

`LoadImage(source)` → `ImageCrop(box)` → `ImageScaleToTotalPixels(1 MP)` → `TextEncodeQwenImageEditPlus(image1 = 裁出的块, image2 = ref)` →
采样(尺寸 = 裁块按 1 MP 缩放后对齐 16)→ `VAEDecode` → `ImageScale(回到框的宽高)` →
`ImageCompositeMasked(destination = source, source = 改过的块, x, y, mask = SolidMask 外圈经 FeatherMask 羽化 32 像素)` → `SaveImage`。
采样器、步数、CFG 与首帧同一套快档;不吃首帧模板预设(预设是按首帧模板节点号写的)

### 校验

- 框:宽高 ≥ 128、在图内、`source` 就是该帧当前图(否则 400 说原因)
- 素材必须是本段绑定且有参考图的;关键帧框选同样适用

---

## 错误处理

- 第二遍 / 局部替换的参考图缺文件:dispatch 报「参考图不存在」失败(不静默跳过)
- 提示词过不了标签校验:规划时抛错
- 局部替换时当前帧已被换掉(框是在旧图上画的):规划时校验 `source` 与当前帧一致,不一致 400

## 测试

- 单测:分槽切两份(3 / 4 / 5 / 6 张);第二遍提示词三种句式;3 张以内参数与工作流与现在相同(回归);`build_qwen` 两遍节点与连线;
  预设改步数两遍都生效;就绪清单文案;估时 ×2;工程包导入重映射 `second_pass` 与 `qwen_region` 的路径;
  局部替换:框对齐 / 外扩 / 夹图内、校验失败的原因、工作流节点与坐标、写回到对的那一格
- Playwright 有头自测:demo 剧加一段三角色 + 场景同框,看到「两遍合成」提示;在首帧上拖框 → 选角色 → 生成 → 历史里出现新版本,截图
- **云机实测**(两件都没按产品形态跑过):
  - 两遍「换脸换装」:实验同场面 3 个种子,三人全对 < 2/3 → 停下报告,不合入
  - 局部替换:拿实战段 5 首帧(李福丢了幞头)框住李福、选李福,3 个种子;框外逐像素差 = 0(羽化带除外)、框内人眼认对 ≥ 2/3

## 风险

- 换脸换装与实验的「留位再加人」不同,效果未知 —— 云机实测把关
- 局部替换的框太小,Qwen 放大到 1 MP 后再缩回,细节可能糊;框太大等于整图重画 —— 界面提示「框住整个人」
- 羽化带内会有新旧像素混合,人物边缘可能有轻微重影
