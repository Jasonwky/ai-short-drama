# AI 短剧控制台 · P7 参考模式与四视图 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 视频的参考帧从「只当参考图喂」改成**钉住**(首帧钉第 0 帧、尾帧钉最后一帧),支持「首帧 / 首尾帧 / 尾帧」三种参考模式;角色新增**四视图**(正面图出的横版四宫格),作为视频的参考图。

**Architecture:** H3 工作流在现有 ref2va 之后串 `MiniMaxH3AddGuide`(锚点 = 图 + 帧号),条件依次传过去再接引导器 —— 锚定走条件里的 `minimax_keyframes`,现有 ref2va 权重就能用。
规划层按段落的参考模式决定 <Picture 1> 用哪张帧、钉哪几帧,绑定角色的四视图补进剩下的图槽。尾帧与首帧同一套合成,用段落新增的尾帧图提示词;
四视图以正面图为输入、Qwen 快档出图。库结构升到 v6(两个新列),失效传播新增「四视图」事件(只作废视频)。

**Tech Stack:** Python 3.14 标准库 · 现有 FastAPI / Jinja2 / Playwright · 云机 ComfyUI `250b2e95` 的 `MiniMaxH3AddGuide` 节点(已在云机上,不装任何东西)。**不加依赖。**

## 背景与约定

- **依据**:设计 §6.2 参考模式、§七 角色四视图;`spike-results/2026-09-26-参考锚定与四视图云机实测.md`(本计划全部设计的实测数据):

  | 实测 | 结果 |
  |---|---|
  | 只当参考图喂、只有首帧 1 张参考图 | 第一帧对首帧图差 9.0(守得住) |
  | 只当参考图喂、多 1 张四视图参考图 | 第一帧差 **74.2**(比两张不同图的 35.9 还大:守不住) |
  | ref2va + AddGuide 钉首帧(第 0 帧)与尾帧(-1),参考图 2 张 | 第一帧差 11.9,最后一帧对尾帧图差 **6.5** |
  | 四视图:Qwen 快档 / 标准档 | 快档 2/2 合格;标准档 1/1 不合格(第 4 格又画了背面) |
  | 四视图当 H3 参考图 | 人物与四视图是同一个人、衣着一致 |

- **本计划定下的设计决定**(有异议先停下来问):
  - **`first` 模式也改成锚定**:这会改变现有段落出视频的工作流(多两个节点)。只当参考图喂的做法在参考图变多时实测守不住首帧,
    而四视图一上就是多参考图 —— 不锚定,四视图就不能用
  - 实现的参考模式:`first`、`first_last`、`last`。`key` / `first_last_key` / `anchors`(中间关键帧)与 `text_only` 的视频生成**照旧报「尚未实现」**

  - 尾帧**用 Qwen 合成**(与首帧同一套素材槽位与快档),提示词是段落新增的「尾帧图提示词」;不做「用下一段首帧当尾帧」
    (下一段的首帧常常就是从本段视频抽的尾帧,会绕成环)

def test_h3_anchors_chain_add_guides_into_the_conditioning():
    """锚点 = LoadImage + MiniMaxH3AddGuide,条件依次串过去,最后接到引导器;latent 仍是 ref2va 的联合 latent
    (2026-09-26 云机实测:ref2va + 串 AddGuide 能把首帧钉在第 0 帧、尾帧钉在最后一帧)。"""
    wf = build_h3("<Picture 1> 是首帧。<Picture 2> 是林小雨的四视图", ["f.png", "fv.png"], None, 192, 9,
                  size=(768, 1344), anchors=[("f.png", 0), ("last.png", -1)])
    assert _dangling(wf) == []
    guides = [n for n in wf.values() if n["class_type"] == "MiniMaxH3AddGuide"]
    assert [g["inputs"]["frame_idx"] for g in guides] == [0, -1]
    assert guides[0]["inputs"]["positive"] == ["12", 0] and guides[1]["inputs"]["positive"] == ["41", 0]
    assert all(g["inputs"]["latent"] == ["12", 1] and g["inputs"]["vae"] == ["6", 0] for g in guides)
    assert wf["13"]["inputs"]["conditioning"] == ["43", 0]
    assert [wf[g["inputs"]["image"][0]]["inputs"]["image"] for g in guides] == ["f.png", "last.png"]
