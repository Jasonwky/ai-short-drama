# 港片画风(hk90)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 加画风预设「90 年代港产武侠片」(hk90):资产 / 首帧 / 视频提示词按它拼,光线随场景昼夜,资产图带负向提示词,导出时逐段套港片调色,题甲可切换画风。

**Architecture:** 画风仍是 `drama/styles.py` 里的数据;`Style` 增加可选字段,其它预设不填 → 拼出的提示词逐字节不变。拼句仍在 `drama/art.py`(纯函数),光线由场景 `time` 字段选昼 / 夜。调色是新模块 `cut/grade.py`(ffmpeg 滤镜串),只在 `export.run` 编码前逐段套,检测仍吃原片。

**Tech Stack:** Python 3.14、pytest、SQLite、ffmpeg(本机)、FastAPI + Jinja 面板、Playwright 有头自测。

Spec:`docs/superpowers/specs/2026-10-31-港片画风-design.md`(含 §6 自查 G1–G8)。依据:`spike-results/2026-10-31-降低AI感调研.md`。

```python
NIGHT_WORDS = ("夜", "黄昏", "傍晚", "入夜", "晚")


def is_night(scene) -> bool:
    """按场景的「时间」字段分昼 / 夜(港片画风选光线用);没有场景 = 白天。"""
    return scene is not None and any(w in (scene["time"] or "") for w in NIGHT_WORDS)


def asset_prefix(style: Style, table: str) -> str:
    return style.asset_prefix[table] if style.asset_prefix else style.prefix


def frame_suffix(style: Style, art: Art, scene=None) -> str:
    """拼在首帧 / 尾帧 / 关键帧提示词之后:画风 + 时代 + 不要什么。
    港片画风(有 frame_look):质感 + 按场景昼夜选光线,**不写 Avoid**(CFG 1 下否定词会被当描述,spec 2026-10-31 §1)。"""
    era = f" Setting: {art.era}." if art.era else ""
    if style.frame_look:
        light = style.light_night if is_night(scene) else style.light_day
        return f" {style.frame_look}, {light}.{era}"
    return f" {style.prefix}.{era} Avoid: {style.avoid}."


def video_phrase(style: Style, art: Art, scene=None) -> str:
    """视频画风。老预设:中文拼在末尾;港片:英文开场句(调用方放在提示词最前,H3 指南)。"""
    if style.video_en:
        return style.video_en["night" if is_night(scene) else "day"] + (f" Setting: {art.era}." if art.era else "")
    return f"画面风格:{style.zh}。" + (f"时代:{art.era}。" if art.era else "")
```

```python
# -*- coding: utf-8 -*-
"""导出调色(spec 2026-10-31-港片画风-design.md §2):只在导出编码前逐段套,检测仍吃原片。

hk90 = 实验调色链 tmp/realism_ab/wxgrade.sh 固化(spike-results/2026-10-31-降低AI感调研.md §6–7):
高光提取模糊后 screen 叠回(泛光)→ 抬黑压白 → 暗部偏青蓝 / 高光偏暖橙 → 降饱和 → 先缩后放降一档清晰度 → 时域颗粒 → 暗角。
踩坑:blend 在 YUV 下对色度平面 screen 会整片偏洋红,必须先转 gbrp。参数是一次手调(n=1),**未标定**。
"""
from __future__ import annotations

import subprocess
from pathlib import Path

GRADES = {
    "hk90": ("[0:v]format=gbrp,split[base][hl];"
             "[hl]curves=all='0/0 0.6/0 1/1',gblur=sigma=22[glow];"
             "[base][glow]blend=all_mode=screen:all_opacity=0.5,"
             "curves=all='0/0.06 0.5/0.48 1/0.95',"
             "colorbalance=rs=-0.10:gs=-0.02:bs=0.12:rm=0.02:gm=0.0:bm=-0.02:rh=0.10:gh=0.04:bh=-0.10,"
             "eq=saturation=0.9,"
             "scale=iw/2:-2,scale=iw*2:-2,gblur=sigma=0.5,"
             "noise=alls=20:allf=t+u,"
             "vignette=PI/4.5,format=yuv420p[v]"),
}


def filters(key: str) -> str:
    if key not in GRADES:
        raise KeyError(f"未知调色预设 {key!r},可选:{sorted(GRADES)}")
    return GRADES[key]


def apply(src: Path, out: Path, key: str) -> None:
    """只动画面,音轨原样拷贝;失败抛 CalledProcessError(不吞)。"""
    out.parent.mkdir(parents=True, exist_ok=True)
    subprocess.run(["ffmpeg", "-v", "error", "-y", "-i", str(src), "-filter_complex", filters(key), "-map", "[v]",
                    "-map", "0:a?", "-c:v", "libx264", "-crf", "16", "-preset", "medium", "-c:a", "copy", str(out)],
                   check=True, capture_output=True)


def measure(path: Path, at: float = 1.0) -> dict:
    """一帧的平均饱和度与亮度低位(signalstats SATAVG / YLOW),读回自检用。"""
    p = subprocess.run(["ffmpeg", "-v", "error", "-ss", str(at), "-i", str(path), "-frames:v", "1",
                        "-vf", "signalstats,metadata=print:file=-", "-f", "null", "-"],
                       check=True, capture_output=True, text=True)
    kv = dict(line.split("=", 1) for line in p.stdout.splitlines() if "=" in line and line.startswith("lavfi."))
    return {"sat": float(kv["lavfi.signalstats.SATAVG"]), "ylow": float(kv["lavfi.signalstats.YLOW"])}
```
