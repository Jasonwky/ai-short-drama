# AI 短剧控制台 · P14 多关键帧 · 草稿档 · 切镜说明 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一段可钉 1–3 张中间关键帧;视频可选 10 步草稿档并在卡片与导出页标明「少步数」;界面如实说明 H3 切镜不可控;纯文字模式写明不支持的原因。

**Architecture:** 关键帧搬进新表 `segment_keyframe`(库结构 v10,编号永不复用,旧关键帧迁移时搬过去并标 `legacy_v9`,段落上的三列删掉)。
生成任务仍挂在段落上,参数里记 `keyframe_id`;「这条任务写到哪」集中在 `tools/drama/targets.py`,写回、挑版本、补全、改参重跑、留痕、工程包都经它。
草稿档只是任务参数里的 `steps: 10`,dispatch 叠完模板预设后按 `BasicScheduler` 设步数;「这条视频几步出的」只由 `dispatch.steps_of` 读实际交出去的图来判。

**Tech Stack:** Python 3.14 标准库 · 本机 ffmpeg · 现有 FastAPI / Jinja2 / Playwright。**不加依赖。** 库结构升到 v10。

```python
def test_keyframes_come_back_in_time_order(store, sample):

    """删了的关键帧,历史任务参数里的 keyframe_id 不能指到新加的那张。"""
```

```python
def add_keyframe(store: Store, segment_id: int, time_sec: float, image_prompt: str = "",
                 frame_path: str | None = None) -> int:
    """给段落加一张中间关键帧。张数上限、时刻范围由 readiness 判(超了给人话原因),这里不拦。"""
    get(store, "segment", segment_id)
    return _insert(store, "segment_keyframe", {"segment_id": segment_id, "time_sec": time_sec,
                                               "image_prompt": image_prompt, "frame_path": frame_path})


def keyframes(store: Store, segment_id: int) -> list[sqlite3.Row]:
    """本段的关键帧,按时刻先后。"""
    return store.conn.execute("SELECT * FROM segment_keyframe WHERE segment_id = ? ORDER BY time_sec, id",
                              (segment_id,)).fetchall()


def delete_keyframe(store: Store, keyframe_id: int) -> None:
    """删一张关键帧。它的生成历史(task)与文件保留;编号不复用。"""
    with store.write() as c:
        if c.execute("DELETE FROM segment_keyframe WHERE id = ?", (keyframe_id,)).rowcount == 0:
            raise KeyError(f"segment_keyframe {keyframe_id} 不存在")
```

### Task 2: 规则、规划与写回改读新表(核心)

**readiness 逐张判**:每张离两头 ≥ 0.5 秒、不与首尾锚点重合、有提示词、有图;张与张之间 ≥ 0.5 秒(= 12 帧,帧号不会相同,所以不另判帧号);> 3 张阻塞,> 2 张出警告「此数量未经真机验证(实测到 2 张)」;原「首尾帧 + 关键帧」警告保留。`key_frame_index` 改成收秒数。

**规划**:`key_frame_problems / plan_key_frame` 改收关键帧行号;任务仍挂在段落上(task 表不改),参数里 `writes = key_frame_path`、`keyframe_id = 行号`;视频在模式锚点之后**按时刻先后**逐张钉。首帧 / 尾帧 / 关键帧共用 `_image_problems` 与 `_plan_image`。

```python
def keyframe_id(store: Store, task: sqlite3.Row) -> int | None:
    """关键帧任务指向的那张关键帧;已删除 = None。"""
    p = json.loads(task["params_json"])
    if "keyframe_id" in p:
        kid = p["keyframe_id"]
    else:
        row = store.conn.execute("SELECT id FROM segment_keyframe WHERE segment_id = ? AND legacy_v9 = 1",
                                 (task["target_id"],)).fetchone()
        kid = row[0] if row else None
    if kid is None or store.conn.execute("SELECT 1 FROM segment_keyframe WHERE id = ?", (kid,)).fetchone() is None:
        return None
    return kid


def slot(store: Store, task: sqlite3.Row) -> tuple[str, int | None, str]:
    p = json.loads(task["params_json"])
    if p.get("writes") == KEY_WRITES:
        return "segment_keyframe", keyframe_id(store, task), "frame_path"
    return task["target_type"], task["target_id"], p["writes"]


def current(store: Store, task: sqlite3.Row) -> str | None:
    """这条任务的写回位置上现在挂的产物;目标已删 = None。"""
    table, row_id, field = slot(store, task)
    if row_id is None:
        return None
    row = store.conn.execute(f"SELECT {field} FROM {table} WHERE id = ?", (row_id,)).fetchone()
    return row[0] if row else None
```

```python
    """表单里的关键帧 [(行号,新加的为 None;秒;提示词)] 与要删的行号。空白的「加一张」不算。"""
    ids, times, prompts = ([str(v) for v in form.getlist(k)] for k in KEY_FORM)
    if not len(ids) == len(times) == len(prompts):
        raise ValueError("关键帧表单不完整(行号 / 时刻 / 提示词的个数对不上)")
    rows = []
    for kid, t, prompt in zip(ids, times, prompts):
        if not kid and not t.strip() and not prompt.strip():
```

```python
        return None
    return (datetime.fromisoformat(task["finished_at"]) - datetime.fromisoformat(task["started_at"])).total_seconds()


def _draft_check(data_root: Path, full: dict, draft: dict) -> dict:
    """草稿档:实际提交的工作流是 10 步;耗时与定稿比(都从 worker 看到 running 起算)。"""
    sent = json.loads((data_root / "outputs/tasks" / str(draft["id"]) / SUBMITTED).read_text(encoding="utf-8"))
    steps = graphs.steps(sent["submitted"])
    if steps != DRAFT_STEPS:
        raise RuntimeError(f"草稿档实际提交的是 {steps} 步,不是 {DRAFT_STEPS} 步")
    a, b = _seconds(full), _seconds(draft)
    ratio = round(b / a, 3) if a and b is not None else None
    if ratio is not None and ratio >= DRAFT_MAX_RATIO:

    return {"task": draft["id"], "steps": steps, "seconds": b, "full_seconds": a, "ratio": ratio}
```
