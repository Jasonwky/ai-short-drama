# 台词配音 第 2 期:段落台词音频 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 段落的台词按说话人的定稿音色逐句克隆、拼成一条音频,Whisper 回听按拼音逐句判;判不过换种子重合成(≤ 3 次);人在「视频」面板合成 / 试听 / 挑版。

**Architecture:** `kind = 'tts'` 任务(v24 已放开)。规划 `gen/tts.py` 定死台词、每个说话人的定稿音色(路径 + sha256 + 参考文本)、停顿与种子;
执行 `serve/ttser.py` 与 `voicer` 同套路:等卡 → 上传参考音频 → 云机 `serve/tts_remote.py`(Base 模型,一次加载,按尝试序号换种子)→ wav + 每句起止回本机 →
上传 wav → `align_remote.py` 转写 → 本机 `speech.line_hits` 逐句判。写回 `segment.line_audio_path` 只填空位。
**过期**(`gen/tts.stale`):现在的台词或任一说话人的定稿音色与任务快照不同。spec 第 4 节。

**不在本期:** 段长由音频定、视频接音频(第 3 期);每段必须有台词的闸门(第 4 期)。
