# 台词配音 第 3 期:视频接台词音频 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 视频按段落当前的台词音频出:H3 用 `MiniMaxH3AddGuide` 把音频钉在第 0 帧,帧数由音频时长定;没有台词 / 没有台词音频 / 台词音频过期的段落不许规划视频;
当前视频不是按当前台词音频出的,视频卡片提示。spec 第 4、5 节,第 6.1 节的「规划拦无台词段」提前到本期(视频没音频可钉)。

**Architecture:**
- 库结构 v25:`task.result_sec REAL`(产物时长;tts 完成时写)。规划只读库,不读文件。
- `gen/tts.current_audio(store, seg) -> (path, sha256, sec) | None`:当前台词音频(由 tts 任务产出且没过期)。
- `plan_video`:参数加 `audio_guide`(路径),台本快照加 `line_audio: {path, sha256, sec}`;
  `frames = frames_for(clamp(sec, 训练下限))`,`sec` 超训练上限 → 规划拒绝(拆段或删句);删掉提示词里的声音描述与 `SILENT`,台词照旧逐字写。
- `workflows.build_h3(..., guide_audio=None)`:有就加 `LoadAudio` + `MiniMaxH3AddGuide(audio, audio_vae=7, frame_idx=0)`,串在图片锚点之后。
- `dispatch`:`_uploads` 带上 `audio_guide`;`build_workflow` 传上传名。
- 视频面板:当前视频的 `script.line_audio.sha256` ≠ 当前台词音频 → 提示「当前视频不是按当前台词音频出的」。

**测试夹具**:`tests/drama/conftest.sample` 给林小雨一条定稿音色、段落一条已完成的 tts 任务(`result_sec = 8.0`,与段落时长一致,原有帧数断言不变)。
