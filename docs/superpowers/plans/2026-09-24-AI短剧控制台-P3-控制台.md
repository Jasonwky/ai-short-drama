# AI 短剧控制台 · P3 控制台 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 P1/P2 的能力做成本地网页控制台:立项 → 剧本 → 资产 → 分镜 → 参考帧 → 视频 → 主机,七个真正可操作的环节面板,配 Playwright 有头全面自测与一条命令的验收入口。

**Architecture:** FastAPI + Jinja2 服务端渲染,一个很小的原生 JS(切集、分镜实时校验、在途任务自动刷新),不走 CDN。控制台进程内一个后台线程跑 P2 的 `Worker`(每台云机一个),面板只做「规划任务 / 挑版本 / 改内容」,提交与推进仍由 worker 负责。面板登记在一张注册表里,Playwright 自测遍历这张表。

**Tech Stack:** Python 3.14 · FastAPI 0.133 · uvicorn 0.41 · Jinja2 3.1 · httpx(TestClient)· Playwright 1.58(Chromium)· ffmpeg(假 GPU 生成样片)。**全部已装在本机,不新增依赖。**

## 关键设计决定(执行时不要改)

1. **服务端渲染 + 表单 POST/重定向**,JS 只做三件小事。理由:面板逻辑都在 Python 里,可用 TestClient 测;前端无构建步骤、无 CDN(纯本地)。
2. **面板只规划,不提交**。点「生成」= 写一条参数定死的 task;后台 worker 负责提交与推进(P2 的接管语义不变)。
3. **plan/confirm 统一成一个模式**:同一个 POST 地址,先算 `Impact`;有代价且没带 `confirm=1` → 渲染确认页(原表单字段原样带回);确认后才落盘。
4. **种子显式**:表单里预填一个随机种子,**显示在页面上、随表单提交**,人可以改。任务拿到的永远是显式整数。
5. **判活两层分开说**:「隧道未通」与「隧道已通但 ComfyUI 没响应」是两种处理方式不同的故障。
6. **假后端隔离**:`fake_backend()` 只在测试和 `selftest` 里用;自测在全新临时目录建演示工程;页面顶部常驻「假后端」横幅。
7. **全局面板带 `?d=<剧id>`**:从「主机」回来时左侧步骤不丢上下文(自测截图发现的问题)。
8. **`<link rel="icon" href="data:,">`**:有头浏览器会请求 `/favicon.ico`,404 会被自测记成 console.error(无头跑发现不了,有头跑发现的)。

# -*- coding: utf-8 -*-
"""风格预设 —— 设计 §七:「是数据不是代码」。

`drama.style` 存预设的 key;生成资产参考图时,预设给出提示词前缀与 avoid 项。
写实真人排第一:用户 2026-09-23 定「以后用生成的写实真人出片」(角色一律是虚构人物)。
"""
from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class Style:
    key: str
    label: str
    prefix: str   # 拼在资产提示词最前面
    avoid: str    # 拼在最后:不要什么


STYLES: tuple[Style, ...] = (
    Style("realistic", "写实真人",
          "photorealistic photograph, real human, realistic skin texture, natural lighting, 50mm lens",
          "anime, illustration, cartoon, 3D render, painting"),
    Style("anime", "二次元",
          "high quality anime illustration, clean line art, cel shading",
          "photograph, photorealistic, 3D render"),
    Style("semi3d", "半写实 3D",
          "semi-realistic 3D character render, soft global illumination",
          "flat illustration, photograph"),
)


def get_style(key: str) -> Style:
    for s in STYLES:
        if s.key == key:
            return s
    raise KeyError(f"未知风格预设 {key!r},可选:{[s.key for s in STYLES]}")
```

# -*- coding: utf-8 -*-
"""资产参考图(角色正面 / 场景空镜 / 道具白底)的规划。

Qwen-Image-Edit 必须有输入图(路线图未决项 #5)。2026-09-23 实测:**纯灰底图 + 「整幅替换」提示词**
能出写实照片质感、无画风残留的素材(`spike-results/2026-09-23-写实真人风格实测.md`)。这里把它定成正式做法。

- 提示词 = 风格前缀 + 资产的 `final_prompt` + 该类资产的硬规范(设计 §6:三视图/无人空镜/白底单品)+ avoid;
- 写实风格下,角色提示词强制写明「虚构人物」—— 不生成任何真实存在的人;
- `final_prompt` 为空、剧没选风格,都直接报错,不用默认值填空。
"""
from __future__ import annotations

import struct
import zlib
from pathlib import Path

from tools.drama import repo
from tools.drama.db import Store
from tools.drama.styles import get_style
from tools.drama.tasks import create_task
from tools.gen.workflows import FRAME_SIZE, QWEN_MODEL

CANVAS = "assets/_canvas/gray_1024.png"

# 各类资产:写回哪个字段、出图尺寸、硬规范
SPEC = {
    "character": ("turnaround_path", lambda aspect: (928, 1664),
                  "Full body, standing straight, front view, arms relaxed, plain white studio background, soft even lighting."),
    "scene": ("image_path", lambda aspect: FRAME_SIZE[aspect],
              "Absolutely no people, no human figures, no silhouettes. Wide establishing shot, eye level, fixed camera."),
    "prop": ("image_path", lambda aspect: (1024, 1024),
             "Single isolated object centered on a pure white background, studio lighting, no people, no hands, no scenery."),
}
FICTIONAL = "A fictional person who does not resemble any real individual."


def _png(width: int, height: int, gray: int) -> bytes:
    def chunk(tag: bytes, data: bytes) -> bytes:
        return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", zlib.crc32(tag + data))
    raw = b"".join(b"\x00" + bytes([gray]) * width for _ in range(height))   # 每行:滤波字节 + 灰度像素
    return (b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", struct.pack(">IIBBBBB", width, height, 8, 0, 0, 0, 0))
            + chunk(b"IDAT", zlib.compress(raw)) + chunk(b"IEND", b""))


def ensure_canvas(data_root: Path) -> str:
    """灰底输入图,不存在就生成。返回相对 data_root 的路径。"""
    path = Path(data_root) / CANVAS
    if not path.exists():
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(_png(1024, 1024, 128))
    return CANVAS


def asset_prompt(table: str, style_key: str, final_prompt: str) -> str:
    style = get_style(style_key)
    who = f" {FICTIONAL}" if table == "character" and style_key == "realistic" else ""
    return (f"Completely replace the entire image with a {style.prefix}.{who} {final_prompt.strip()} "
            f"{SPEC[table][2]} Avoid: {style.avoid}.")


def plan_asset_image(store: Store, table: str, row_id: int, *, seed: int) -> int:
    if table not in SPEC:
        raise ValueError(f"不是资产表:{table}")
    row = repo.get(store, table, row_id)
    drama = repo.get(store, "drama", row["drama_id"])
    problems = []
    if not drama["style"]:
        problems.append("这部剧还没选风格预设(在「立项」里选)")
    if not row["final_prompt"].strip():
        problems.append(f"「{row['name']}」缺少生成描述(final_prompt)")
    if problems:
        raise ValueError(";".join(problems))
    writes, size_of, _ = SPEC[table]
    params = {
        "workflow": "qwen_image", "preset": "baseline", "size": list(size_of(drama["aspect_ratio"])),
        "image_refs": [CANVAS], "writes": writes, "expect_ext": ".png", "style": drama["style"],
    }
    prompt = asset_prompt(table, drama["style"], row["final_prompt"])
    return create_task(store, kind="image", target_type=table, target_id=row_id, model=QWEN_MODEL,
                       params=params, seed=seed, prompt=prompt, refs=params["image_refs"])
```

"""挑历史版本:把某次生成的产物设为「当前版」(设计 §七「历史版本不覆盖」「逐条重绘保留历史」)。

换版本会让下游作废,所以走 plan/confirm 两态(CLAUDE.md):
- 换角色/场景/道具的参考图 → 绑定了它的段落,参考帧和视频全部作废(`invalidation` 的同名事件);
- 换段落首帧/尾帧 → 只有本段视频作废(另一张参考帧不受影响,不清)。
`plan_pick` 只算不改;人看了代价确认后 `confirm_pick` 才落盘。

from __future__ import annotations

import json
from dataclasses import dataclass

from tools.drama import invalidation, repo
from tools.drama.db import Store
from tools.drama.invalidation import Impact
from tools.gen.capability import Capability

_FRAME_FIELDS = ("first_frame_path", "last_frame_path")


@dataclass(frozen=True)
class Pick:
    task_id: int
    target_type: str
    target_id: int
    field: str
    new_path: str
    impact: Impact

    def summary(self) -> str:
        return self.impact.summary()


def plan_pick(store: Store, task_id: int, *, video_cap: Capability, image_cap: Capability) -> Pick:
    task = repo.get(store, "task", task_id)
    if task["state"] != "done":
        raise ValueError(f"task {task_id} 状态是 {task['state']},只有完成的任务能被选为当前版")
    field = json.loads(task["params_json"])["writes"]
    ttype, tid = task["target_type"], task["target_id"]
    if repo.get(store, ttype, tid)[field] == task["result_path"]:
        raise ValueError("这一版已经是当前版")

    if ttype in ("character", "scene", "prop"):
        imp = invalidation.impact(store, ttype, tid, video_cap=video_cap, image_cap=image_cap)
    elif field in _FRAME_FIELDS:
        seg = repo.get(store, "segment", tid)
        if seg["video_path"]:
            imp = Impact((tid,), 0, 1, video_cap.est_seconds(video_cap.frames_for(seg["duration_sec"])))
        else:
            imp = Impact((), 0, 0, 0.0)
    else:
        imp = Impact((), 0, 0, 0.0)   # 换视频:没有下游
    return Pick(task_id, ttype, tid, field, task["result_path"], imp)


def confirm_pick(store: Store, pick: Pick) -> None:
    if pick.target_type in ("character", "scene", "prop"):
        invalidation.apply(store, pick.impact)
    elif pick.field in _FRAME_FIELDS and pick.impact.segment_ids:
        with store.write() as c:
            c.execute("UPDATE segment SET video_path = NULL, subtitle_path = NULL WHERE id = ?", (pick.target_id,))
    repo.update(store, pick.target_type, pick.target_id, **{pick.field: pick.new_path})

# -*- coding: utf-8 -*-
"""操作留痕(CLAUDE.md「三支柱」之一):worker 与控制台的每一行动作都追加到 `<data_root>/journal/worker.log`。"""
from __future__ import annotations

from datetime import datetime, timezone
from pathlib import Path

LOG = "journal/worker.log"


def append(data_root: Path, lines: list[str], *, prefix: str = "") -> list[str]:
    """带 UTC 时间戳追加,返回实际写入的行(调用方可以原样打印)。空列表不写。"""
    if not lines:
        return []
    stamp = datetime.now(timezone.utc).isoformat(timespec="seconds")
    out = [f"{stamp} {prefix}{line}" for line in lines]
    path = Path(data_root) / LOG
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a", encoding="utf-8") as f:
        f.write("\n".join(out) + "\n")
    return out


def tail(data_root: Path, n: int = 50) -> list[str]:
    path = Path(data_root) / LOG
    if not path.exists():
        return []
    return path.read_text(encoding="utf-8").splitlines()[-n:]
```

# -*- coding: utf-8 -*-
"""假执行面:行为像 ComfyClient 的假云机、假隧道、自动出片的假 GPU。

**只给测试与 Playwright 自测用**。控制台的正式入口(`tools.serve.console`)不接受假后端 ——
对应 CLAUDE.md「不可用就明确报错,不静默切 Fake」。自测在独立的临时 data_root 里跑,假产物碰不到真工程。
"""
from __future__ import annotations

import shutil
import subprocess
import tempfile
from pathlib import Path

from tools.gen.assets import _png
from tools.gen.comfy_client import ComfyClient, ComfyError, ComfyUnreachable


class FakeComfy:
    def __init__(self):
        self.reachable = True
        self.reject_next_submit: str | None = None   # 模拟 HTTP 400(工作流本身写错)
        self.uploaded: list[str] = []
        self.submitted: dict[str, dict] = {}
        self.running: list[str] = []
        self.pending: list[str] = []
        self.records: dict[str, dict] = {}
        self.files: dict[str, bytes] = {}
        self._n = 0

    # ── ComfyClient 的接口 ──────────────────────────
    def _up(self):
        if not self.reachable:
            raise ComfyUnreachable("fake: 连不上 ComfyUI")

    def upload_image(self, path, subfolder=""):
        self._up()
        self.uploaded.append(Path(path).as_posix())
        return f"{subfolder}/{Path(path).name}" if subfolder else Path(path).name

    def submit(self, workflow):
        self._up()
        if self.reject_next_submit:
            msg, self.reject_next_submit = self.reject_next_submit, None
            raise ComfyError(f"/prompt 返回 HTTP 400:{msg}")
        self._n += 1
        pid = f"p{self._n}"
        self.submitted[pid] = workflow
        self.pending.append(pid)
        return pid

    def queue_ids(self):
        self._up()
        return list(self.running), list(self.pending)

    def history(self, prompt_id):
        self._up()
        return self.records.get(prompt_id)

    def outputs(self, record):
        return ComfyClient.outputs(self, record)

    def fetch(self, item, dest_dir):
        self._up()
        dest = Path(dest_dir)
        dest.mkdir(parents=True, exist_ok=True)
        out = dest / item["filename"]
        out.write_bytes(self.files[item["filename"]])
        return out

    # ── 测试操控 ────────────────────────────────────
    def start(self, pid):
        self.pending.remove(pid)
        self.running.append(pid)

    def finish(self, pid, filename, data=b"generated"):
        for q in (self.pending, self.running):
            if pid in q:
                q.remove(pid)
        self.files[filename] = data
        self.records[pid] = {"status": {"status_str": "success", "completed": True},
                             "outputs": {"9": {"images": [{"filename": filename, "subfolder": "", "type": "output"}]}}}

    def fail(self, pid, message):
        for q in (self.pending, self.running):
            if pid in q:
                q.remove(pid)
        self.records[pid] = {"status": {"status_str": "error", "completed": False,
                                        "messages": [["execution_error", {"exception_message": message}]]},
                             "outputs": {}}

    def vanish(self, pid):
        """任务从云机消失:不在队列、也不在 history(比如 ComfyUI 被重启过)。"""
        for q in (self.pending, self.running):
            if pid in q:
                q.remove(pid)

def sample_mp4() -> bytes:
    """1 秒 384x672 的测试图样 mp4,用本机 ffmpeg 现生成。没有 ffmpeg 就报错,不假装。"""
    if shutil.which("ffmpeg") is None:
        raise RuntimeError("假 GPU 要用 ffmpeg 生成可播放的样片,本机找不到 ffmpeg")
    with tempfile.TemporaryDirectory() as d:
        out = Path(d) / "sample.mp4"
        subprocess.run(["ffmpeg", "-v", "error", "-y", "-f", "lavfi", "-i", "testsrc=size=384x672:rate=24",
                        "-t", "1", "-pix_fmt", "yuv420p", "-c:v", "libx264", str(out)], check=True)
        return out.read_bytes()


class FakeGpu:
    """把假云机队列里的任务一次跑完:H3(工作流里有 noise_seed)出 mp4,其余出 png。"""
    def __init__(self, comfy: FakeComfy):
        self.comfy = comfy
        self._png = _png(96, 160, 90)
        self._mp4: bytes | None = None

    def run_pending(self) -> int:
        done = 0
        for pid in list(self.comfy.pending) + list(self.comfy.running):
            is_h3 = any("noise_seed" in n["inputs"] for n in self.comfy.submitted[pid].values())
            if is_h3:
                self._mp4 = self._mp4 or sample_mp4()
                self.comfy.finish(pid, f"{pid}.mp4", self._mp4)
            else:
                self.comfy.finish(pid, f"{pid}.png", self._png)
            done += 1
        return done

    gpu = FakeGpu(comfy)

                      fake=True, before_tick=gpu.run_pending)
    return backend, comfy

  P2 真链路实测:云机开机后 ComfyUI **不会自启**,只看隧道会把「ComfyUI 没起」误报成正常。
- `Backend` 决定怎么连执行面。正式入口只用真实后端;假后端只给测试与 Playwright 自测。
"""
from __future__ import annotations

import threading
import time
from collections.abc import Callable
from dataclasses import dataclass, field
from pathlib import Path

from tools.drama.db import Store
from tools.gen import preflight
from tools.gen.comfy_client import ComfyClient, ComfyUnreachable
from tools.serve import journal
from tools.serve.hosts import Host, get_host
from tools.serve.tunnel import TunnelManager
from tools.serve.worker import POLL_SEC, Worker, _ssh_run


@dataclass
class Backend:
    label: str
    client_for: Callable[[Host], object]
    tunnel: object
    run_for: Callable[[Host], preflight.Runner]
    fake: bool = False
    before_tick: Callable[[], None] | None = None   # 假 GPU 在这里「跑完」队列


def real_backend() -> Backend:
    return Backend("云机(真实)", lambda h: ComfyClient(h.local_endpoint), TunnelManager(), _ssh_run)


@dataclass
class HostStatus:
    tunnel_ok: bool = False
    comfy_ok: bool = False
    message: str = "还没检查过"
    running: int = 0
    pending: int = 0
    last_tick: str = ""
    last_lines: list[str] = field(default_factory=list)


def probe(host: Host, backend: Backend) -> HostStatus:
    if not backend.tunnel.ensure(host):
        return HostStatus(message=f"隧道未通(本机端口 {host.local_port})—— 检查云机是否开机、SSH 端口是否变了")
    try:
        running, pending = backend.client_for(host).queue_ids()
    except ComfyUnreachable as e:
        return HostStatus(tunnel_ok=True, message=f"隧道已通,但 ComfyUI 没响应 —— 云机上 ComfyUI 可能没启动({e})")
    return HostStatus(tunnel_ok=True, comfy_ok=True, running=len(running), pending=len(pending),
                      message=f"正常:ComfyUI 队列 运行 {len(running)} / 排队 {len(pending)}")


class Runtime:
    def __init__(self, store: Store, data_root: Path, backend: Backend, poll_sec: float = POLL_SEC):
        self.store = store
        self.data_root = Path(data_root)
        self.backend = backend
        self.poll_sec = poll_sec
        self.status: dict[int, HostStatus] = {}
        self._workers: dict[int, Worker] = {}
        self.last_error = ""          # 后台线程最近一次异常,主机面板上显示
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def host_ids(self) -> list[int]:
        return [r[0] for r in self.store.conn.execute("SELECT id FROM host ORDER BY id")]

    def tick_all(self) -> None:
        if self.backend.before_tick:
            self.backend.before_tick()
        for hid in self.host_ids():
            w = self._workers.get(hid)
            if w is None:
                b = self.backend
                w = self._workers[hid] = Worker(self.store, hid, data_root=self.data_root,
                                                client_for=b.client_for, tunnel=b.tunnel, run_for=b.run_for)
            lines = journal.append(self.data_root, w.tick(), prefix=f"host={hid} ")
            st = probe(get_host(self.store, hid), self.backend)
            st.last_tick = time.strftime("%H:%M:%S")
            st.last_lines = lines
            self.status[hid] = st

    def any_host_ready(self) -> tuple[bool, str]:
        if not self.status:
            return False, "还没有登记云机(在「主机」面板添加)" if not self.host_ids() else "worker 还没跑完第一轮"
        ok = [s for s in self.status.values() if s.comfy_ok]
        return (True, ok[0].message) if ok else (False, next(iter(self.status.values())).message)

    def start(self) -> None:
        def loop():
            while not self._stop.is_set():
                try:
                    self.tick_all()
                    self.last_error = ""
                except Exception as e:   # 不吞:进 journal、挂到主机面板上;线程本身不能悄悄死掉
                    self.last_error = f"{time.strftime('%H:%M:%S')} {type(e).__name__}: {e}"
                    journal.append(self.data_root, [f"worker 本轮异常:{self.last_error}"], prefix="runtime ")
                self._stop.wait(self.poll_sec)
        self._thread = threading.Thread(target=loop, name="drama-worker", daemon=True)
        self._thread.start()

    def stop(self) -> None:
        self._stop.set()
        if self._thread is not None:
            self._thread.join(timeout=30)
```

# -*- coding: utf-8 -*-
"""面板注册表。**Playwright 自测遍历的就是这张表** —— 新面板只要登记进来,自测自动覆盖它。

scope 决定 URL 要什么上下文:global 不要;drama 要 drama_id;episode 要 episode_id。
大纲(P4,依赖 LLM)与成片(P5)在它们有真后端之前**不登记** —— 没有后端的面板只能是空壳,
违反 CLAUDE.md「每个环节是它自己真正的操作面板」。
"""
from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class Panel:
    key: str
    title: str
    scope: str      # global / drama / episode
    path: str       # 可含 {drama_id} / {episode_id}


REGISTRY: tuple[Panel, ...] = (
    Panel("projects", "立项", "global", "/"),
)


def url_for(panel: Panel, drama_id: int | None, episode_id: int | None) -> str | None:
    """这个上下文下面板的地址;缺上下文(还没选剧 / 剧里还没有集)返回 None。"""
    if panel.scope == "drama" and drama_id is None:
        return None
    if panel.scope == "episode" and episode_id is None:
        return None
    url = panel.path.format(drama_id=drama_id, episode_id=episode_id)
    # 全局面板带上当前剧(?d=),从「主机」回来时左侧步骤不丢上下文
    return f"{url}?d={drama_id}" if panel.scope == "global" and drama_id is not None else url

# -*- coding: utf-8 -*-
"""控制台 FastAPI 应用。

- 只听 127.0.0.1(见 `tools.serve.console`),纯本地,绝不上传;
- 领域层抛的 `ValueError` 是「给人看的原因」(缺什么、为什么不行),统一渲染成 400 页面,不是 500;
- `/media/...` 只读地提供 data_root 里的素材与产物,拒绝跳出 data_root 的路径。
"""
from __future__ import annotations

from pathlib import Path

from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles

from tools.serve.panels import common, projects
from tools.serve.runtime import Runtime

STATIC = Path(__file__).resolve().parent / "static"


def create_app(runtime: Runtime) -> FastAPI:
    app = FastAPI(title="AI 短剧控制台", docs_url=None, redoc_url=None, openapi_url=None)
    app.state.runtime = runtime
    app.mount("/static", StaticFiles(directory=str(STATIC)), name="static")
    for mod in (projects,):
        app.include_router(mod.router)

    @app.exception_handler(ValueError)
    async def refused(request: Request, exc: ValueError):
        return common.render(request, "error.html", "", message=str(exc),
                             back=request.headers.get("referer") or "/", status_code=400)

    @app.exception_handler(KeyError)
    async def missing(request: Request, exc: KeyError):
        return common.render(request, "error.html", "", message=f"找不到:{exc.args[0] if exc.args else exc}",
                             back="/", status_code=404)

    @app.get("/media/{rel:path}")
    def media(rel: str):
        root = runtime.data_root.resolve()
        path = (root / rel).resolve()
        if root not in path.parents or not path.is_file():
            raise HTTPException(404, "没有这个文件")
        return FileResponse(path)

    return app

"use strict";

document.addEventListener("DOMContentLoaded", () => {
  // 1. 顶栏切集:保持当前面板,换 episode_id
  const sw = document.querySelector("[data-ep-switch]");
  if (sw) {
    sw.addEventListener("change", () => {
      const m = location.pathname.match(/^\/episode\/\d+(\/.*)$/);
      location.href = m ? `/episode/${sw.value}${m[1]}` : `/episode/${sw.value}/storyboard`;
    });

  // 2. 分镜编辑:描述/时长一改就调代码校验(与保存时同一套规则)
  const form = document.querySelector("[data-live-check]");
  if (form) {
    const out = form.querySelector("[data-live-result]");
    let timer = null;
    const run = async () => {
      const body = new URLSearchParams({
        description: form.elements.description.value,
        duration_sec: form.elements.duration_sec.value,
      });
      const r = await fetch("/api/segment/check", { method: "POST", body });
      const data = await r.json();
      out.innerHTML = data.problems.length

        clearTimeout(timer);
        timer = setTimeout(run, 300);
      }
    });

# -*- coding: utf-8 -*-
"""剧本:按集编辑剧本。本版只有「自带剧本」入口;小说改编 / 梗概生成要 LLM,在 P4。

改剧本 = 该集全部段落作废(`invalidation` 的 script 事件)—— 有已生成产物时先报代价再确认。
"""
from __future__ import annotations

from fastapi import APIRouter, Form, Request
from fastapi.responses import RedirectResponse

from tools.drama import invalidation, repo, rules
from tools.gen.capability import MINIMAX_H3, QWEN_IMAGE_EDIT_2511
from tools.serve.panels.common import confirm_page, needs_confirm, render, rt

router = APIRouter()
CAPS = {"video_cap": MINIMAX_H3, "image_cap": QWEN_IMAGE_EDIT_2511}


@router.get("/drama/{drama_id}/script")
def page(request: Request, drama_id: int):
    store = rt(request).store
    repo.get(store, "drama", drama_id)
    eps = []
    for e in store.conn.execute("SELECT * FROM episode WHERE drama_id = ? ORDER BY number", (drama_id,)):
        n = store.conn.execute("SELECT COUNT(*) FROM segment WHERE episode_id = ?", (e["id"],)).fetchone()[0]
        lo, hi = rules.expected_segment_range(e["script"]) if e["script"].strip() else (0, 0)
        eps.append({"row": e, "n_segments": n, "range": (lo, hi),
                    "problems": rules.check_episode(e["script"], n) if e["script"].strip() and n else []})
    return render(request, "script.html", "script", drama_id=drama_id, eps=eps)


@router.post("/drama/{drama_id}/episodes")
def add_episode(request: Request, drama_id: int):
    store = rt(request).store
    n = store.conn.execute("SELECT COALESCE(MAX(number), 0) + 1 FROM episode WHERE drama_id = ?",
                           (drama_id,)).fetchone()[0]
    repo.add_episode(store, drama_id, n, "script")
    return RedirectResponse(f"/drama/{drama_id}/script", status_code=303)


@router.post("/episode/{episode_id}/script")
async def save(request: Request, episode_id: int):
    store = rt(request).store
    form = await request.form()
    ep = repo.get(store, "episode", episode_id)
    back = f"/drama/{ep['drama_id']}/script"
    text = str(form.get("script", ""))
    if text == ep["script"]:
        return RedirectResponse(back, status_code=303)
    imp = invalidation.impact(store, "script", episode_id, **CAPS)
    if needs_confirm(imp, form):
        return confirm_page(request, summary=imp.summary(), action=f"/episode/{episode_id}/script",
                            fields={"script": text}, back=back, panel_key="script", drama_id=ep["drama_id"])
    if imp.videos or imp.frames:
        invalidation.apply(store, imp)
    repo.update(store, "episode", episode_id, script=text)
    return RedirectResponse(back, status_code=303)
```

from fastapi import APIRouter, Form, Request

from tools.drama import repo

from tools.gen.assets import SPEC, ensure_canvas, plan_asset_image

router = APIRouter()

# 面板上可编辑的文字字段(都在 repo 的写入白名单里)
FIELDS = {
    "character": [("appearance", "外貌"), ("styling", "服装造型"), ("voice_desc", "声音描述(视频里的音色靠它)"),
                  ("final_prompt", "生成描述(英文效果更稳)")],

@router.get("/drama/{drama_id}/assets")
def page(request: Request, drama_id: int):
    store = rt(request).store
    repo.get(store, "drama", drama_id)
    cols = []
    for table in ("character", "scene", "prop"):
        items = []
        for row in store.conn.execute(f"SELECT * FROM {table} WHERE drama_id = ? ORDER BY id", (drama_id,)):
            items.append({"row": row, "current": row[SPEC[table][0]], "tasks": tasks_for(store, table, row["id"])})
        cols.append({"table": table, "label": KIND_LABEL[table], "entries": items, "fields": FIELDS[table]})

@router.post("/drama/{drama_id}/assets")
def add(request: Request, drama_id: int, kind: str = Form(...), name: str = Form("")):

    if not name.strip():
        raise ValueError("名字不能为空 —— 分镜里要用 @名字 引用它")
    try:

    repo.update(store, table, row_id, **{k: str(form.get(k, "")) for k, _ in FIELDS[table]})
    return RedirectResponse(f"/drama/{repo.get(store, table, row_id)['drama_id']}/assets", status_code=303)

# -*- coding: utf-8 -*-
"""分镜:段落表 + 段落编辑(实时代码校验、reference_mode、绑定)。

校验与保存用**同一套**代码规则(`rules.check_segment`),前端只是提前调用它,不另写一份。
改动已出过图/视频的段落 → `segment_prompt` 事件,先报代价再确认。
"""
from __future__ import annotations

from fastapi import APIRouter, Form, Request
from fastapi.responses import JSONResponse, RedirectResponse

from tools.drama import invalidation, repo, rules
from tools.gen.capability import MINIMAX_H3, QWEN_IMAGE_EDIT_2511
from tools.serve.panels.common import confirm_page, needs_confirm, readiness, render, rt

router = APIRouter()
CAPS = {"video_cap": MINIMAX_H3, "image_cap": QWEN_IMAGE_EDIT_2511}
MODES = [("first", "首帧参考"), ("text_only", "纯文字(无参考帧)"),
         ("last", "尾帧参考(视频生成未实现)"), ("first_last", "首尾帧(视频生成未实现)")]
TEXT_FIELDS = ("description", "image_prompt", "video_prompt", "reference_mode")


def _seconds(text: str) -> float | None:
    text = text.strip()
    if not text:
        return None
    try:
        return float(text)
    except ValueError as e:
        raise ValueError(f"时长要填数字(秒),填的是 {text!r}") from e


def _names(store, sql, sid):
    return [r[0] for r in store.conn.execute(sql, (sid,))]


@router.get("/episode/{episode_id}/storyboard")
def page(request: Request, episode_id: int):
    runtime = rt(request)
    store = runtime.store
    ep = repo.get(store, "episode", episode_id)
    segs = []
    for s in store.conn.execute("SELECT * FROM segment WHERE episode_id = ? ORDER BY number", (episode_id,)):
        checks = readiness(runtime, s["id"])
        segs.append({
            "row": s,
            "scene": repo.get(store, "scene", s["scene_id"])["name"] if s["scene_id"] else "",
            "chars": _names(store, "SELECT c.name FROM segment_character sc JOIN character c ON c.id = sc.character_id "
                                   "WHERE sc.segment_id = ? ORDER BY sc.position", s["id"]),
            "props": _names(store, "SELECT p.name FROM segment_prop sp JOIN prop p ON p.id = sp.prop_id "
                                   "WHERE sp.segment_id = ? ORDER BY sp.position", s["id"]),
            "missing": [c.msg for c in checks if not c.ok],
        })
    return render(request, "storyboard.html", "storyboard", episode_id=episode_id, ep=ep, segs=segs)


@router.post("/episode/{episode_id}/segments")
def add(request: Request, episode_id: int):
    store = rt(request).store
    n = store.conn.execute("SELECT COALESCE(MAX(number), 0) + 1 FROM segment WHERE episode_id = ?",
                           (episode_id,)).fetchone()[0]
    sid = repo.add_segment(store, episode_id, n)
    return RedirectResponse(f"/segment/{sid}/edit", status_code=303)


@router.get("/segment/{segment_id}/edit")
def edit_page(request: Request, segment_id: int):
    runtime = rt(request)
    store = runtime.store
    seg = repo.get(store, "segment", segment_id)
    drama_id = repo.get(store, "episode", seg["episode_id"])["drama_id"]
    assets = repo.segment_assets(store, segment_id)
    all_of = {t: store.conn.execute(f"SELECT id, name FROM {t} WHERE drama_id = ? ORDER BY id", (drama_id,)).fetchall()
              for t in ("character", "scene", "prop")}
    return render(request, "segment_edit.html", "storyboard", episode_id=seg["episode_id"], seg=seg, modes=MODES,
                  all_of=all_of, bound_chars={c["id"] for c in assets["characters"]},
                  bound_props={p["id"] for p in assets["props"]}, checks=readiness(runtime, segment_id))


@router.post("/segment/{segment_id}/edit")
async def save(request: Request, segment_id: int):
    store = rt(request).store
    form = await request.form()
    seg = repo.get(store, "segment", segment_id)
    assets = repo.segment_assets(store, segment_id)
    new = {k: str(form.get(k, "")) for k in TEXT_FIELDS}
    new["duration_sec"] = _seconds(str(form.get("duration_sec", "")))
    scene_id = int(form["scene_id"]) if form.get("scene_id") else None
    chars = [int(x) for x in form.getlist("character_ids")]
    props = [int(x) for x in form.getlist("prop_ids")]

    changed = (any(new[k] != seg[k] for k in new) or scene_id != seg["scene_id"]
               or chars != [c["id"] for c in assets["characters"]] or props != [p["id"] for p in assets["props"]])
    back = f"/segment/{segment_id}/edit"
    if not changed:
        return RedirectResponse(back, status_code=303)
    imp = invalidation.impact(store, "segment_prompt", segment_id, **CAPS)
    if needs_confirm(imp, form):
        fields = {k: str(form.get(k, "")) for k in (*TEXT_FIELDS, "duration_sec", "scene_id")}
        fields |= {"character_ids": [str(c) for c in chars], "prop_ids": [str(p) for p in props]}
        return confirm_page(request, summary=imp.summary(), action=back, fields=fields, back=back,
                            panel_key="storyboard", episode_id=seg["episode_id"])
    if imp.videos or imp.frames:
        invalidation.apply(store, imp)
    repo.update(store, "segment", segment_id, **new)
    repo.set_scene(store, segment_id, scene_id)
    repo.bind_characters(store, segment_id, chars)
    repo.bind_props(store, segment_id, props)
    return RedirectResponse(back, status_code=303)


@router.post("/api/segment/check")
def live_check(description: str = Form(""), duration_sec: str = Form("")):
    try:
        dur = _seconds(duration_sec)
    except ValueError as e:
        return JSONResponse({"problems": [str(e)], "ok_msg": ""})
    problems = rules.check_segment(description, dur, MINIMAX_H3)
    return JSONResponse({"problems": problems, "ok_msg": "时长与子镜头结构合规"})
```

def seed_demo(store: Store, data_root: Path) -> dict:

def _free_port() -> int:
    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        return s.getsockname()[1]


def _serve(runtime: Runtime) -> tuple[uvicorn.Server, str]:
    port = _free_port()
    server = uvicorn.Server(uvicorn.Config(create_app(runtime), host="127.0.0.1", port=port, log_level="warning"))
    threading.Thread(target=server.run, daemon=True).start()
    deadline = time.time() + 20
    while not server.started:
        if time.time() > deadline:
            raise RuntimeError("自测用的控制台 20 秒内没起来")
        time.sleep(0.1)
    return server, f"http://127.0.0.1:{port}"


def _wait_for(page, selector: str, timeout_s: float) -> bool:
    """等某个元素出现。页面有在途任务时自己会 10 秒刷一次;这里更勤快地主动刷新。"""
    deadline = time.time() + timeout_s
    while time.time() < deadline:
        if page.locator(selector).count():
            return True
        time.sleep(1.5)
        page.reload()
    return False


def run(out_dir: Path) -> dict:
    from playwright.sync_api import sync_playwright

    out_dir.mkdir(parents=True, exist_ok=True)
    work = Path(tempfile.mkdtemp(prefix="drama-selftest-"))
    store = Store(work / "drama.db")
    ids = seed_demo(store, work)
    backend, _ = fake_backend()
    runtime = Runtime(store, work, backend, poll_sec=1)
    runtime.start()
    server, base = _serve(runtime)
    report = {"base": base, "work_dir": str(work), "headed": True, "panels": [], "flows": []}
    try:
        with sync_playwright() as pw:
            browser = pw.chromium.launch(headless=False, slow_mo=250)
            page = browser.new_page(viewport={"width": 1440, "height": 900})
            errors: list[str] = []
            page.on("pageerror", lambda e: errors.append(f"JS 异常:{e}"))
            page.on("console", lambda m: errors.append(f"console.{m.type}:{m.text}") if m.type == "error" else None)
            page.on("response", lambda r: errors.append(f"HTTP {r.status} {r.url}") if r.status >= 500 else None)

            for i, p in enumerate(REGISTRY, 1):
                errors.clear()
                url = base + url_for(p, ids["drama"], ids["episode"])
                page.goto(url)
                key = page.locator(KEY_SELECTOR[p.key])
                rendered = key.count() > 0 and key.first.is_visible()
                main_text = page.locator(f'main[data-panel="{p.key}"]').inner_text().strip()
                footer = page.locator("footer").inner_text().strip()
                shot = out_dir / f"{i:02d}_{p.key}.png"
                page.screenshot(path=str(shot), full_page=True)
                problems = list(errors)
                if not rendered:
                    problems.append(f"关键元素 {KEY_SELECTOR[p.key]} 没渲染出来")
                if len(main_text) < 10:
                    problems.append("面板内容几乎为空")
                if footer != "Powered by MiniMax H3":
                    problems.append(f"页脚署名不对:{footer!r}")
                report["panels"].append({"panel": p.key, "title": p.title, "url": url, "ok": not problems,
                                         "problems": problems, "screenshot": str(shot)})

            seg = ids["segment"]
            for key, button, wait_sel, timeout in (
                    ("frames", "[data-generate-frame]", f"#seg-{seg} .current-media img", 40),
                    ("videos", "[data-generate-video]", f"#seg-{seg} .current-media video", 60)):
                errors.clear()
                p = next(x for x in REGISTRY if x.key == key)
                page.goto(base + url_for(p, ids["drama"], ids["episode"]))
                page.locator(button).first.click()
                appeared = _wait_for(page, wait_sel, timeout)
                shot = out_dir / f"flow_{key}.png"
                page.screenshot(path=str(shot), full_page=True)
                problems = list(errors) + ([] if appeared else [f"{timeout}s 内没等到 {wait_sel}"])
                report["flows"].append({"flow": f"{key}: 点「生成」→ 产物出现在面板上", "ok": not problems,
                                        "problems": problems, "screenshot": str(shot)})
            browser.close()
    finally:
        server.should_exit = True
        runtime.stop()
        store.close()
    report["ok"] = all(x["ok"] for x in report["panels"] + report["flows"])
    (out_dir / "selftest.json").write_text(json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")
    return report

    ap = argparse.ArgumentParser(description="控制台 Playwright 全面自测(一律有头,会弹出浏览器)")

    print(f"截图与报告:{out}")
    return 0 if report["ok"] else 1


if __name__ == "__main__":
    sys.exit(main())

# -*- coding: utf-8 -*-
"""验收入口:一条命令跑完三层(设计 §十一、CLAUDE.md 控制台纪律)。

    1 单测                 python -m pytest -q
    2 Playwright 有头自测   遍历注册表每个面板 + 点按钮链路,逐个截图存档
    3 功能整链(真云机)     一个段落出首帧 + 视频,溯源齐全(字幕 / 标识 / 拼接在 P5,本层暂只覆盖到视频)

判决四态 PASS / FAIL / PARTIAL / SKIP —— **SKIP 永不计为 PASS**(M-6)。任一层没跑,总判决就不是 PASS。
**入口拒绝无头模式**:Playwright 测试一律有头(CLAUDE.md 硬约束);无头的验收是「人看不见的验收」。

    python -X utf8 -m tools.serve.accept                                 # 第 3 层 SKIP → 总判决 PARTIAL
    python -X utf8 -m tools.serve.accept --real-ssh-host H --real-ssh-port P --key-ref K \\
        --models-dir /root/autodl-tmp/comfyui-models --character C --scene S --prop R
"""
from __future__ import annotations

import argparse
import json
import os
import subprocess
import sys
from datetime import datetime
from pathlib import Path

REAL_ARGS = ("real_ssh_host", "real_ssh_port", "key_ref", "models_dir", "character", "scene", "prop")


def verdict(layers: list[dict]) -> str:
    states = [x["state"] for x in layers]
    if "FAIL" in states:
        return "FAIL"
    if all(s == "PASS" for s in states):
        return "PASS"
    return "PARTIAL"


def _run(cmd: list[str], log: Path, env: dict | None = None) -> int:
    with log.open("w", encoding="utf-8") as f:
        return subprocess.run(cmd, stdout=f, stderr=subprocess.STDOUT, env=env).returncode


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description="AI 短剧控制台验收入口(三层,有头)")
    ap.add_argument("--headless", action="store_true", help=argparse.SUPPRESS)
    ap.add_argument("--real-ssh-host")
    ap.add_argument("--real-ssh-port", type=int)
    ap.add_argument("--key-ref")
    ap.add_argument("--models-dir")
    ap.add_argument("--character")
    ap.add_argument("--scene")
    ap.add_argument("--prop")
    a = ap.parse_args(argv)
    if a.headless:
        print("验收入口拒绝无头模式:Playwright 测试一律有头(CLAUDE.md 硬约束),验收要让人看见每个面板被打开。",
              file=sys.stderr)
        return 2

    out = Path("outputs/accept") / datetime.now().strftime("%Y%m%d-%H%M%S")
    out.mkdir(parents=True, exist_ok=True)
    py = [sys.executable, "-X", "utf8"]
    layers: list[dict] = []

    print("第 1 层 单测 …", flush=True)
    rc = _run([*py, "-m", "pytest", "-q"], out / "1_pytest.log")
    layers.append({"layer": "单测", "state": "PASS" if rc == 0 else "FAIL", "log": str(out / "1_pytest.log")})

    print("第 2 层 Playwright 有头自测(会弹出浏览器)…", flush=True)
    rc = _run([*py, "-m", "tools.serve.selftest", "--out", str(out / "selftest")], out / "2_selftest.log")
    layers.append({"layer": "Playwright 有头自测", "state": "PASS" if rc == 0 else "FAIL",
                   "log": str(out / "2_selftest.log"), "screenshots": str(out / "selftest")})

    given = [k for k in REAL_ARGS if getattr(a, k)]
    if not given:
        layers.append({"layer": "功能整链(真云机)", "state": "SKIP",
                       "reason": "没给云机参数 —— 这一层没跑,不算通过"})
    elif len(given) < len(REAL_ARGS):
        missing = sorted(set(REAL_ARGS) - set(given))
        layers.append({"layer": "功能整链(真云机)", "state": "FAIL", "reason": f"云机参数不全:缺 {missing}"})
    else:
        print("第 3 层 功能整链(真云机,约 17 分钟)…", flush=True)
        env = {**os.environ, "MSYS_NO_PATHCONV": "1"}
        rc = _run([*py, "-u", "-m", "tools.serve.e2e_first_segment", "--data-root", str(out / "e2e"),
                   "--ssh-host", a.real_ssh_host, "--ssh-port", str(a.real_ssh_port), "--key-ref", a.key_ref,
                   "--models-dir", a.models_dir, "--character", a.character, "--scene", a.scene, "--prop", a.prop],
                  out / "3_e2e.log", env=env)
        layers.append({"layer": "功能整链(真云机)", "state": "PASS" if rc == 0 else "FAIL",
                       "log": str(out / "3_e2e.log"), "note": "字幕 / 标识 / 拼接在 P5,本层暂只覆盖到视频"})

    result = {"verdict": verdict(layers), "layers": layers}
    (out / "report.json").write_text(json.dumps(result, ensure_ascii=False, indent=2), encoding="utf-8")
    for x in layers:
        print(f"  [{x['state']}] {x['layer']}" + (f" —— {x['reason']}" if "reason" in x else ""))
    print(f"总判决:{result['verdict']}(报告 {out / 'report.json'})")
    return 0 if result["verdict"] == "PASS" else 1


if __name__ == "__main__":
    sys.exit(main())

## 自查记录

- **计划代码 == 验证过的代码**:文档由脚本生成,代码块原样取自隔离目录;逐步增长的 `app.py` 与注册表先以初始形态出现、
  每个面板任务字面替换增长;重放完的树与隔离目录**逐文件**比对一致(含模板、CSS、JS)才写出文档
- **设计覆盖**:§七 的 8 个面板中 6 个在本计划(剧本只含自带入口),大纲 / 成片明确移到 P4 / P5;「贯穿所有面板」三条
  (增量补全 = 只对缺的段落点生成、历史不覆盖、页脚署名)都有;§十一 验收入口三层 + 拒绝无头 + SKIP 不算过
- **类型 / 名字一致**:`Backend` / `Runtime` / `HostStatus`(runtime 定义,fakes / common / selftest 使用)、
  `Panel` / `REGISTRY` / `url_for`(注册表定义,common / selftest / 测试使用)、`plan_pick` / `confirm_pick` / `Pick`、
  `plan_asset_image` / `ensure_canvas` / `CANVAS`
- **有意不做**:资产上传与从图反推描述、改剧的风格(风格建剧时定,改风格 = 全剧作废,要单独设计)、多机并发调度
- **已知限制**:段落保存是四次写入(字段 / 场景 / 角色 / 道具)而非一个事务;中途失败会留下部分更新。单人本地使用下风险低,记为后续项
