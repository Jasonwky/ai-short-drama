## P2 执行层

**目标**:把闸门 0 的一次性执行器,变成常驻、可恢复、可审计的生成管线。

**范围**(设计 §四、§5.3、§6.1–6.2):
- **隧道管理**:控制面自建 `ssh -N -L`;两层判活(进程 / `queue_counts()`);接管已存在的隧道;退避 5s→300s。
  🔴 闸门 0 实测:**Windows 控制面上没有 `setsid`**,必须用 `subprocess.Popen` + `DETACHED_PROCESS`
- **worker**:扫库推进 task 状态机(`tools/drama/tasks.py` 的迁移表);`waiting_host` 可恢复;
  控制面重启后按 `external_id` **接管**在途任务(闸门 0 用 `--attach` 救回过一条)
- **生成后端**:`qwen_image`(4 步 Lightning 默认档,合成首帧**显式给目标尺寸**)、`minimax_h3`(20 步);
  提示词经 `tools/drama/tags.py` 展开与校验;**提交前跑 `lora_compat` 形状预检**
- **按模型分组调度**:同一模型的任务连着跑,少换权重(显存容量从 `host.vram_gb` 推导)
- 产物落盘 + 写 `task.result_path` / `result_sha256`

**完成标准**:单测全绿(用假 ComfyUI 覆盖:断线重连、接管、非法迁移、LoRA 不兼容拒绝);
**开卡跑一次真链路**:一个段落从 pending 走到 done,出首帧图 + 视频,溯源字段齐全。

**带过来的已知问题**:H3 无可用加速档(用户决定接受 20 步);参考音频有复读风险,默认不喂。

**实际范围调整**:资产生成(角色四视图 / 场景空镜 / 道具白底)移到 P3 —— 执行层已通用,P3 做面板时只补对应的 planner 函数。
真链路验收另发现并修复「视频提示词缺台词」(ASR 0.05 → 1.00),遗留 5 项见验收文档第五节。

## P3 控制台

**目标**:八个环节面板的网页控制台(列表分步 + 深度面板,huobao 式形态、独立实现)。

**范围**(设计 §七、§十一,CLAUDE.md 控制台纪律):
- FastAPI 服务 + 轻前端;面板 registry
- 八个面板:立项 · 大纲 · 剧本 · 资产 · 分镜 · 参考帧 · 视频 · 成片;每个是真正的操作面板,不是「run + 看 JSON」
- readiness 清单直接显示「还差什么」;失效传播**先弹代价再确认**;历史版本可挑
- 页脚常驻 **"Powered by MiniMax H3"**(许可证 III.3.a / IV.2)
- **Playwright 有头遍历全部面板、逐个截图存档**;验收入口一条命令跑三层、**拒绝无头模式**

**完成标准**:单测 + Playwright 自测全绿 + 截图存档(CLAUDE.md「三者缺一不算做完」)。

**实际范围**:七个面板(立项 · 剧本 · 资产 · 分镜 · 参考帧 · 视频 · 主机)。大纲 → P4、成片 → P5(没有真后端前不登记空壳面板);资产的上传图片与从图反推描述未做。P2 遗留的「验收夹具不写 journal」「ComfyUI 未运行无提示」在本阶段解决。

## P4 LLM 环节

**目标**:剧本三入口(小说改编 / 梗概生成 / 自带剧本)与分镜拆解。

**范围**(设计 §6.3,CLAUDE.md LLM 调用纪律全套):
- 结构化输出(Anthropic Structured Outputs),`additionalProperties: false` + enum 闭集
- LLM 拆分镜后**由 `tools/drama/rules.py` 判卷**,不合格带错误回炉,轮次上限后 fail-loud;**禁默认值填空**
- `refusal` / `max_tokens` 两个逃逸口显式分支;产物落 `journal/`,人工审批后锁定
- 写入经 `repo` 白名单;plan/confirm 两态
- **真 LLM 契约测试**(不许用 Fake 冒充)
- 角色的**声音描述**(`voice_desc`)由 LLM 生成、人可改 —— 闸门 0-4 表明音色一致性靠它,不靠参考音频

**完成标准**:确定性路径单测 + 至少一条真 LLM 契约测试 + 控制台里可操作。

**实际实现**:LLM 服务为 SynScale(用户指定),默认模型 deepseek-v4-flash(实测选型见 spike-results)。不做:给已有段落的集重拆分镜 / 重写剧本、超 6 万字小说分批。

## P5 成片与合规

**目标**:把段落视频变成**可上架**的一集。

**范围**(设计 §6.6–6.9):
- 尾帧衔接:从已完成视频 ffmpeg 抽最后一帧作下一段首帧
- 拼接成集
- 字幕 → P5b:用户定在云机上对齐(本机下载模型太慢;Qwen3-ForcedAligner 仓库无 LICENSE 文件、不支持 Python 3.14),见 spike-results/2026-09-24-GB45438原文核对与导出实测.md §4.1
- **AI 标识**:画面起始 + 持续显示,含「人工智能/AI」+「生成/合成」,不得缩小虚化(GB 45438-2025)
- **AIGC 元数据**:五要素;`ProduceID` 与溯源报告作品编号同一个;另出无显式标识版本(隐式保留)
- 溯源报告:整集 task 链导出
- ✅ 附录 E 原文已核对(7 个字段)

**实际实现(P5a)**:显式标识全程左上角、字高按最短边 7.5%;每次导出出带 / 不带显式标识两版;7 项读回自检。不做:字幕(P5b)、配乐混音。

**完成标准**:导出一集成片,标识与元数据经检查器验证,溯源报告与 task 表一致。
