# 抖音 / 快手 / B 站 / 番茄 / 起点 内容获取实测(参考库子项目 1 前置调研,第一轮:未登录)

日期:2026-11-07 · 触发:用户「抖音、快手、B 站、番茄、起点也按这个方法实测」(方法同 `2026-11-07-红果短剧内容获取实测.md`)
范围(有边界):每个平台 = robots.txt + 榜单 / 首页 + 1 个详情或正片 / 正文页;普通 curl 读 robots,其余用**有头** Playwright(普通 Chromium,不改指纹、不过验证码、不伪造签名),每页访问 1 次、停留约 10 秒。
**本轮只测未登录**;登录后能看到什么是第二轮(要用户本人扫码)。

## 结论先说

| 平台 | robots.txt 对通用爬虫 | 未登录用普通浏览器打开 | 能自动化的部分 | 卡在哪 |
|---|---|---|---|---|
| **番茄小说** | `Allow: /` 全放行 | 榜单、书页、阅读页都能打开 | 书名、作者、榜单名次、章节目录 | **正文与简介都是字体加密**:阅读页可见文本 27 %(99 / 360)、榜单页 38 %(941 / 2500)是私用区字符 —— 屏幕上靠自定义字体显示,复制下来是乱码 |
| **起点** | 读不到(robots 本身被 JS 反爬挡住,HTTP 202 + `probe.js`) | **滑块拼图验证**,页面空白 | 无 | 安全验证;不做过验证码 |
| **B 站** | 基本放行(只禁 `/medialist/detail/` 与几种语言目录) | 排行榜能打开(标题、播放、弹幕数、BV 号);**视频页 412「触发安全风控策略,访问被拒绝」**;搜索页空白 | 排行榜元数据 | 自动化浏览器触发风控 |
| **快手** | `User-agent: * Disallow: /`(只给点名搜索引擎放行)| 首页推荐能打开,`<video>` 直接挂快手 CDN 的 mp4 地址;互动要登录 | 无(robots 对我们这类程序是整站禁止) | robots |
| **抖音** | 只为点名的搜索引擎 / AI 爬虫写了规则,没有 `User-agent: *` 组 | 热榜页只渲染出框架(「抖音热榜」标题),列表没出来;整页截图超时 | 待第二轮(登录后) | 未登录内容出不来 |

**一句话**:不登录、不破解的前提下,五家里只有 **B 站排行榜** 和 **番茄的书名 / 榜单名次 / 目录** 能稳定自动拿;正片与正文要么加密(番茄字体)、要么被风控 / 验证码 / robots 挡住。

## 反证

- **「B 站 412 是网络抖动?」** 412 页面原文写明是「安全风控策略」;同一会话里排行榜页正常,只有视频页被拒 —— 是针对性风控,不是网络问题。
- **「番茄乱码是编码问题?」** 不是:书名、章节标题、字数、日期都正常,只有正文与简介里成段缺字,缺的全是 U+E000–F8FF 私用区 —— 典型的自定义字体映射(反复制措施)。
- **「起点空白是加载慢?」** 截图是明确的滑块验证码弹窗。

## 对设计的影响

1. **适配器按平台分档**,不一刀切:
   - **能自动**:红果(榜单 + 详情 + 剧评,见红果文档)、B 站排行榜元数据、番茄的书名 / 榜单名次 / 目录。
   - **需登录后再判断**:抖音、B 站视频、快手 —— 第二轮测。
   - **不自动**:起点(验证码)、快手(robots 整站禁止)、番茄正文(字体加密)。
2. **不做**:过滑块验证码、改浏览器指纹躲风控、反解番茄字体映射或对正文截图 OCR 来绕开字体加密(都是在规避对方的技术措施)。
3. **小说正文的正当来源**:作者公开的免费章节里**没加密**的部分、平台「版权专区」(番茄首页就有入口)谈授权、或人工投递(人用正常途径读到、自己整理的梗概)。

## 范围决定(用户 2026-11-07)
