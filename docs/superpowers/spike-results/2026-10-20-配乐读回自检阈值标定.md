# 配乐读回自检的阈值标定

- **日期**:2026-10-20
- **对应设计**:`specs/2026-10-20-配乐白屏与替换神情-design.md` 一「配乐混音」—— 读回自检加一项「配乐」
- **代码**:`tools/cut/music.py` 的 `readback` / `plateau` / `outside`,常量 `WANT_MARGIN_DB`、`OUTSIDE_BELOW_DB`、`FLOOR_DB`
- **脚本**:`tmp/music_proto2.py`、`tmp/calib.py`(tmp 不入库;做法见下)

## 结论先说

1. **参照音轨用「同一条音频链、不混配乐重编一遍」,不用原片直接解码。**
   这样第一条 cue 之前,成片音轨与参照**逐样本相同**(差异 = −∞);cue 之后只剩 AAC 码率分配(位池)带来的差异,
   比原音轨低 **38 dB 以上**。直接拿原片解码当参照,AAC 重编噪声一直在(比对白低约 37 dB),cue 之前也量不到 0。
2. **cue 内判「音乐在」:成片 − 参照 的电平 ≥ 按包络独立算出的音乐电平 − 6 dB**(只量满音量区间:扣掉淡入淡出、台词及前后 0.3 秒过渡)。
   预期电平由 Python 独立算:音乐文件解码 × `gain_at`,不经 ffmpeg 的音量表达式 —— 用数据审混音,不用混音审混音。
   没混的时候差异是 −∞(逐样本相同),混了的时候差异 ≥ 预期(AAC 噪声只会让它更大),6 dB 是余量。
3. **cue 外判「没漏混、原音轨没被压低」:差异 ≤ 原音轨电平 − 25 dB(或低于 −80 dBFS)。**
   按 cue 外的每一段整体量(不是逐 0.5 秒窗口:对白里的安静窗口会让相对值跳到 −33 dB,窗口太碎会误报)。
   实测正例离上限最近 **12.7 dB**;对白被压低 3 dB 的反例超出上限约 **14 dB**。
4. 没有 cue:PASS,写明「本集无配乐」。

## 反证:为什么不是别的解释

- **「cue 外差异小,是因为配乐本来就小」?** 不是:cue 之前的差异是 −∞,与配乐大小无关(配乐还没开始,两条链输入逐样本相同、编码器确定)。
  cue 之后的差异来自 AAC 位池:不混配乐时这段也是逐样本相同(「没混」反例的 cue 外 = −∞)。
- **「cue 内过了,是因为 AAC 噪声凑出来的」?** 没混配乐时 cue 内差异是 −∞,AAC 噪声只在**真混了东西**时才出现;
  而且和弦 −14 / −24 dB 两档测到的差异与独立算的预期相差 ≤ 0.4 dB,电平对得上。
- **「−34 dB 档测到的比预期高 10 dB 以上,是不是混多了」?** 那一档音乐本身(−62 dBFS)低于 AAC 位池差异,测到的是两者之和 —— 所以只设下限、不设上限。
  这是有意的:上限会在安静配乐上误报。

## 局限(如实)

- **没有用真实音乐标定**:本机没有有许可的音乐文件,用的是粉红噪声与合成和弦。真实音乐有静音段落 —— 量的区间里音乐本身低于 −80 dBFS 时,
  这一项判 FAIL 并提示「调整起止避开静音段」(fail-loud,宁可拦也不放过)。
- **两组真 H3 片、单一码率(AAC 128k)**;cue 外的 25 dB 余量(最近离上限 12.7 dB)在更长的成片、更多 cue 的情况下没测过。
- 这两组没有字幕,台词区间的扣除只在单测样片上走过(`tests/cut/test_export.py`)。
- 对白被压低不到约 0.5 dB 时测不出(按算:压低 0.5 dB 时差异 ≈ 对白 − 25 dB,正好在上限上)—— 混音链用 `amix normalize=0`,单测 `test_mixed_level_follows_the_envelope` 守住「原音轨不衰减」。

### 反证

- **「PASS 是因为 AAC 噪声凑出来的」?** 不是:反例里同一条链不混音乐,cue 内差异是 −∞(逐样本相同);而三档实测与独立算的预期差 ≤ 0.5 dB,随音量每降 6/8 dB 实测也同步降 5.9/7.6 dB —— 测到的就是音乐本身。
- **「真实音乐有静音段会误判」?** 这首氛围曲在量的 14 s 里预期电平都在 −47 dBFS 以上,远高于 −80 的下限,没触发「音乐近乎无声」分支;
  换成开头有长静音的曲子仍可能触发(按设计是 fail-loud 提示挪起点),本次没覆盖。
- **「cue 外 12.1 dB 余量只是碰巧」?** 三档分别 12.1 / 14.6 / 15.9 dB,随音乐变小而变大(cue 后的 AAC 位池差异随配乐变小),与上文合成组 12.7–26.7 dB 的规律一致。

### 局限

- 一首曲子(合成器氛围,不是古风民乐)、一集、单一码率;副本里去掉了被白屏检测拦下的段落 2。
- 台词很密,满音量区间只剩 14 s,且被切成 6 小段(最短 0.4 s);更密的剧集可能落到「整条几乎都在台词里」的回退分支(量整条),本次没走到。

### 追加测量:台词处的压低能不能读回(只量数,没改产品代码)

> 目的:判断读回自检能否加「台词处确实压低了」一项。用同一份副本与导出 #4 / #5 / #6,另导 #7(−14 dB、`duck_db = 0`,即「压低失效」的样子)。
> 原始输出 `tmp/music_real/duck.log`、`results.json` 的 `duck_measure`。

**量的区间**:合并后的台词区间 ∩ [cue 起点 + 淡入, 终点 − 淡出] = 7 段共 **25.8 s**(6.0–9.42、10.42–15.14、17.89–25.41、29.82–31.26、34.09–36.15、41.48–45.16、46.47–49.46)。
0.3 s 过渡都在台词区间**之外**(包络在台词前后各 0.3 s 斜坡),区间内是满压低。参照 = 读回自检同一个参照(同链不混配乐的重编),单声道 16 kHz。

各列:**预期** = 音乐文件 × `gain_at`(gain + duck)独立算的电平;**实测差异** = 成片 − 参照;
**AAC 误差** = 实测差异 − 预期音乐(逐样本相减后的残差,混了音乐之后 AAC 重编带来的误差);**投影增益** = ⟨差异, 预期音乐⟩ / ⟨预期音乐, 预期音乐⟩,换成 dB(0 dB = 混进去的音乐与包络完全一致)。
同一区间里对白(参照)电平 −13.2 dBFS。

| 情形 | 预期压低电平 | 实测差异 | AAC 误差 | 实测 − 预期 | 投影增益 |
|---|---|---|---|---|---|
| −14 dB,压低 −10 | −42.9 | −41.6 | −47.4 | +1.2 | −0.08 dB |
| −20 dB,压低 −10 | −48.9 | −45.2 | −47.6 | +3.7 | −0.08 dB |
| −28 dB,压低 −10 | −56.9 | −50.0 | −51.0 | +6.9 | −0.20 dB |
| 不混音乐的重编 − 参照(−14 档的 cue) | −42.9 | **−∞** | — | — | — |
| **−14 dB,`duck_db = 0`(压低失效),按 −10 的包络判** | −42.9 | **−32.8** | −36.0 | **+10.1** | **+9.95 dB** |
| 同上,按它自己的包络(duck 0)算 | −32.9 | −32.8 | −48.6 | +0.1 | −0.05 dB |

(#7 的 9 项读回自检全 PASS:「配乐」项只量非台词区间,差异 −32.9 / 预期 −32.9 —— **现有自检确实看不出压低失效**,与上文结论第 5 条一致。)

**「不混音乐的重编 − 参照」为什么是 −∞**:两者是同一条音频链、同样的输入,编码器确定,逐样本相同 —— 这不是 AAC 误差底噪。
真正的底噪只在**混了东西之后**才出现,所以表里用「实测差异 − 预期音乐」的残差当 AAC 误差:约 −47 ~ −51 dBFS,比对白低 34–38 dB,与上文 cue 外的量级一致。

**判据比较**:

| 判据 | 三档正常 | duck=0 | 分得开吗 |
|---|---|---|---|
| 实测差异 ≤ 预期 + X dB(能量) | 需 X ≥ 6.9(−28 档) | 超出 10.1 | 只剩 X = 7–10 这 3 dB 窗口,X = 8.5 时两边各 1.6 dB 余量;**音量再低就分不开**:−28 档压低后的音乐(−56.9)已低于 AAC 误差(−51),实测被误差撑高,更安静的配乐(如上文 −34 档)会被误判 FAIL |
| \|投影增益\| ≤ 3 dB(相关) | 最大 0.20 dB,余量 ≥ 2.8 dB | +9.95 dB,超出 6.95 dB | **分得开**:AAC 误差与音乐基本不相关,在 25.8 s(约 41 万样本)上相关一投影就被平均掉;−28 档音乐比误差低 6 dB 仍估得准(−0.20 dB) |

**结论**:

1. **按能量比(实测差异 vs 预期 + X)分不开**,原因是台词处压低后的音乐与 AAC 重编误差同一量级(−28 档已低于误差 6 dB),能量判据只能在 −14 / −20 档用,窗口 3 dB,不建议。
2. **按相关投影分得开**:建议判据「台词区间(满压低部分)里,成片 − 参照 在预期音乐上的投影增益与 1 相差不超过 ±3 dB」。
   三档正常 −0.08 / −0.08 / −0.20 dB(余量 ≥ 2.8 dB),压低失效 +9.95 dB(超出 6.95 dB)。这一判据同样能顺带抓「音量设错」(投影增益偏离 0)。
3. **没测过的**(如实):压低失效只导了 −14 档;−28 档压低失效时投影增益预期也是约 +10 dB(投影不受误差电平主导),**未实测**。
   一首曲子、一集;台词区间 25.8 s,台词很短的剧集样本少、投影方差会变大,门限要不要随时长放宽没量过。是否落进产品由协调者决定,本次没改代码。
