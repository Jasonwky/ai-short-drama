- **日期**:2026-10-03 ~ 10-08
- **起因**:用户要把 ComfyUI 的节点编辑界面嵌进控制台,「本地修改好,再提交到云机」,且**云机关着也能改**;
  改完的工作流既要能存成模板预设,也要能对某一条任务改参重跑(用户 2026-10-03 定,选方案 A:本机提供前端 + 轻量后端垫片)
- **证据等级**:A(本机可复现的确定性实测,有头浏览器)
- **出处**:实验脚本 `tmp/spike-comfy-fe/probe.py`、`roundtrip.py`(tmp 不入库);节点清单缓存自新云机(4080 SUPER,ComfyUI `250b2e95`)

| # | 结论 | 落到哪 |

| 1 | ✅ **前端可以完全脱离真后端在本机跑起来**:只需垫 8 个只读接口,`window.app` 完整初始化,`app.loadApiJson` / `app.graphToPrompt` 都在 | 方案 A 成立 |

## 二、前端要的接口(有头浏览器打开页面 30 秒,逐轮补垫片)

| 轮 | 结果 |
|---|---|
| 1:除静态文件外全部 404 | 停在初始化:`/api/users`、`/api/system_stats`、`/api/features` 拿不到就不往下走;`window.app` 未挂上 |
| 2:补 8 个只读接口 | 完整初始化(界面自动中文),`window.app.loadApiJson` / `graphToPrompt` 可用 |

第 2 轮补的 8 个(内容按 ComfyUI 真后端的格式):`/api/users`(`{"storage":"server","migrated":true}`)、`/api/features`、`/api/system_stats`、
`/api/settings`、`/api/extensions`(`[]`)、`/api/embeddings`(`[]`)、`/api/i18n`、`/api/object_info`(缓存)。

第 2 轮仍 404、但**不阻塞编辑**的:`/ws`(WebSocket,前端会一直重连、刷控制台报错)、`/api/jobs`、`/api/prompt`、`/api/userdata*`、
`/api/workflow_templates`、`/api/global_subgraphs`、`/api/experiment/models`;以及 `POST /api/settings/<键>`(前端写设置)。
→ 正式实现要给 `/ws` 一个空连接、`POST /api/settings/*` 存本机、`POST /api/prompt` **明确拒绝并提示「回控制台提交」**(不许绕过任务表)。

## 三、往返比对(量法:`build_qwen` / `build_h3` 拼出的 API JSON → `loadApiJson` → `graphToPrompt().output`,只比 class_type + inputs)

| 工作流 | 节点 | 差异 |
|---|---|---|
| Qwen 首帧合成(快档,2 张参考图) | 27 → 27 | 无 |
| H3 ref2va(2 张参考图 + 2 个 AddGuide 锚点) | 20 → 20 | `CreateVideo.color_space` 补了 `sRGB`;`SaveVideo` 补了 `format.codec = auto`(动态子参数) |

两处都是 `/object_info` 里该输入的默认值 → 语义不变。**反证 · 为什么不是丢了东西**:节点数一致、所有连线(`[节点, 输出号]`)一致、
我们写的中文 `_meta.title` 在画布上照样显示;差异只出现在我们模板**没写**的可选输入上。

## 四、挂在子路径下(实测 3,`tmp/spike-comfy-fe/subpath.py`)

前端放在 `/comfy/` 下打开:`window.app` 照常初始化,**所有接口都打到 `/comfy/api/...` 与 `/comfy/ws`**,
不会撞上控制台自己的 `/api/...`。只有两个图标文件仍请求根路径:`/assets/favicon.ico`、`/assets/images/favicon_progress_16x16/frame_9.png`
→ 控制台要接住这两个,否则 404 会被有头自测记成 console.error。
