## 五、遗留(不在本次修)

1. **命令行在 Git Bash 下要加 `MSYS_NO_PATHCONV=1`**,否则云机路径被改写。PowerShell/cmd 下不受影响。P3 起由控制台发起,不再经 shell
2. **产物文件名前缀仍是 `gate0_`**(模板里 SaveImage 的 `filename_prefix`)。本地按 `outputs/tasks/<id>/` 隔离,不影响正确性;云机 output 目录里与闸门 0 产物混在一起。随 P3 资产生成改模板时一并改
3. **验收夹具不写 `journal/`**:journal 只在 worker CLI 的 `main()` 里写,夹具直接调 `Worker.tick()`。本次日志在 `tmp/e2e-p2*.log`。P3 由控制台驱动 worker 时应把 journal 写入挪进 `Worker`
4. **提示词里的「固定机位」不被遵守**(见 3.3)
5. **ComfyUI 不随云机开机自启**,本次手工拉起。P3 的主机面板应能显示「ComfyUI 未运行」,而不只是「隧道未通」
