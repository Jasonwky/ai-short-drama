# 参考来源的用户协议 / 网站声明条款(参考库子项目 1)

日期:2026-11-07 · 触发:第 1 段设计复核第 5 条「只看了 robots,没读用户协议」
范围(有边界):红果、晋江、纵横、17K、七猫 5 家;只找三类条款 —— **录制 / 截屏**、**下载 / 复制 / 存储**、**自动访问 / 抓取**。
量法:有头 Playwright 打开首页,取渲染后页脚里名字含「协议 / 条款 / 声明 / 政策」的链接,存协议正文,按关键词(爬 / 抓取 / 程序 / 插件 / 录制 / 截屏 / 下载 / 复制 / 转载 / 镜像 / 采集 / 商业 / 汇编 / 改编)逐行查。
**这不是法律意见**,只是把条款原文摆出来,供用户决定。

## 结论先说

| 来源 | 找到的文本 | 录制 / 截屏 | 复制 / 存储 | 自动抓取 |
|---|---|---|---|---|
| **纵横** | 用户协议 + 法律声明 | ❌ 明文禁止「截屏、内容分享图、拍屏、OCR 识别等方式将服务内容复制…存储到未经书面同意的任何渠道」 | ❌ 「营利性或非营利性的目的」都不得复制、制作衍生著作;法律声明对**所有访问者**:不得对作品内容「复制、抄袭、转载」 | ❌ 明文禁止「通过技术手段或其他不正当手段抓取…以获取本服务的内容」 |
| **17K** | 用户协议 | 没写 | ❌ 「任何商业或非商业目的」不得复制;违约须「销毁任何已经获得的…文字」 | 没有专门条款(只禁第三方插件 / 外挂登录) |
| **七猫** | 用户协议 + 版权声明 | 没写 | ❌ 同 17K 措辞;版权声明对所有访问者:不得「复制、抄袭、转载」作品内容 | 只禁「未经授权的插件、外挂或第三方工具」干扰服务 |
| **晋江** | 只找到「权利声明」 | 没写 | 声明里只说版权归原作者、本站提供存储展示 | 没写 |
| **红果** | **网页上没有**(首页、详情页、播放页、登录浮层都没有协议链接) | 未知 | 未知 | 未知 |

**一句话**:robots 允许 ≠ 协议允许。纵横三类都明文禁止;17K、七猫禁止复制和存储(不分商业还是非商业);晋江的用户协议这次没找到;红果的协议只在 App 里(「我的 → 关于红果 → 用户协议」,出处为旧版本经验文章)。

## 条款原文(摘录)

**纵横**
- 用户协议 5.2.1(5):「将本产品及服务以及与产品和服务相关的内容进行商业及非商业化使用」
- 5.2.1(7):「对幻想纵横拥有知识产权的内容进行监视、使用、出租、出借、复制、修改、链接、转载、汇编、发表、出版,建立镜像站点等」
- 同章另一组(1):「采取截屏、内容分享图、拍屏、ORC识别等方式将服务内容进行复制、发行、表演、传播、存储到未经幻想纵横事先书面同意的任何渠道」
- 同组(2):「通过技术手段或其他不正当手段抓取、破解幻想纵横接口,以获取本服务的内容,以及通过修改程序代码,使用模拟器等方式获取本服务相关的内容」
- 8.2:「未经幻想纵横或相关权利人事先书面同意,您不得为任何营利性或非营利性的目的…修改、拷贝、改编…复制、发行…制作衍生著作…」
- 法律声明:「未经幻想纵横及/或相关权利人明确书面许可,不得对本网站任何组成部分(包括作品页面、作品段落、作品内容等)进行修改、分发、再造、复制、抄袭、交易、转载等」

**17K(中文在线)**
- 用户协议(2):「对中文在线拥有知识产权的内容进行使用、出租、出借、复制、修改、链接、转载、汇编、发表、出版、建立镜像站点等」
- 9.2:「未经中文在线或相关权利人书面同意,您不得为任何商业或非商业目的…对任何该信息、资料、文字…进行修改、拷贝…复制、发行…制作衍生著作…同时您必须销毁任何已经获得的上述信息、资料、文字…」

**七猫**
- 用户协议 3.1.2:「您不得使用未经公司授权的插件、外挂或第三方工具对本协议项下的服务进行干扰、破坏、修改或施加其他影响」
- 4.2:「未经公司或相关权利人书面同意,您不得为任何商业或非商业目的…对任何平台相关信息、资料、文字…进行修改…复制、发行…制作衍生著作…」
- 版权声明 2:「未经七猫公司或相关权利人明确书面许可,不得对本网站任何组成部分(包括作品页面、作品段落、作品内容等)进行修改、分发、再造、复制、抄袭、交易、转载等」

**晋江**:权利声明「本站作品…版权均为原创者所有,本站仅提供上传、存储及展示功能」;用户协议没找到(帮助中心文章 136 / 183 是「如何开启 JavaScript」等,不是协议)。

## 反证

- **「不登录就不受用户协议约束?」** 用户协议约束的是注册用户;但纵横「法律声明」、七猫「版权声明」写的是「本网站任何组成部分」,对象是所有访问者。而且红果录屏本身就要登录。
- **「只做分析,不发布,算不算复制?」** 条款列的是「复制、存储」,没有「仅分析」的例外;17K、七猫还写明了「非商业目的」也不行。分析用途能不能算合理使用(著作权法第 24 条「个人学习、研究」),是法律判断,本文不下结论 —— 我们的用途是给商业短剧做创作参考,不是纯个人学习。
- **「robots 已经允许了?」** robots 是给爬虫的访问约定,不等于许可复制内容;两者是两回事。

## 对设计的影响(待用户决定)

1. 小说正文「抓下来存进库」与纵横、17K、七猫的条款直接冲突;纵横连自动抓取本身都明文禁止。
2. 红果的协议要在 App 里看原文,才能判断「登录后网页录屏」有没有被禁止。
3. 元数据(榜单名次、热度数字、标签、简介)和剧评不在上面这些「作品内容」条款的直接对象里,风险明显小一些;但纵横的「监视」一词范围很宽。
