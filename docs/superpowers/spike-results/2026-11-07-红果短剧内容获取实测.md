# 红果短剧内容获取实测(参考库子项目 1 前置调研)

日期:2026-11-07 · 触发:用户要求「直接调研,看看红果短剧里面的视频能否拿到(模式是切集时看广告)」
范围(有边界):红果官网 `hongguoduanju.com` 的公开页面 + 3 个第三方下载工具的公开说明。**不做**任何签名伪造、解密、设备标识伪造;只用普通 HTTP 请求读公开页面。

## 结论先说

| 想要的东西 | 能否不破解拿到 | 依据 |
|---|---|---|
| 榜单(热播榜 / 真人 / AI / 漫剧,每日更新) | ✅ 能 | `/rank/hot-real-drama` 等 4 个榜,robots 允许;每部带名次、热度、评分、收藏、点赞、标签、简介 |
| 剧集详情(热度、点赞、收藏、榜单名次、标签、演员、简介、集数) | ✅ 能 | `/detail?series_id=…`,在官方 sitemap 里(`seo-important.xml` 3740 条),robots 允许 |
| 热评 / 剧评(观众写的整剧剧情梳理、看点评价) | ✅ 能 | 详情页直接渲染;实测《掌上珠》剧评 141 条,头几条就是全剧情节梳理 + 「为什么上头」 |
| 视频正片(前 5 集) | ✅ 登录后网页可看 → 可录屏 | 见下方「补测」:扫码登录后网页播放器能完整播第 1–5 集(720P、无广告);未登录只有第 1 集 10 秒预览 |
| 视频正片(第 6 集起) | ❌ 网页不能 | 带锁,只在 App 里;App 的流是 **CENC-AES-CTR 加密**,不录屏就只能解密(不做) |
| 搜索 | ⚠️ 不建议 | `/query/` 被 robots 禁止;关键词检索改为在 sitemap + 榜单 + 分类的元数据里本地检索 |
| 逐集播放页 | ⚠️ 不建议 | `/player/*/*` 被 robots 禁止 |

**一句话**:红果能自动拿到的是「热度 + 剧情简介 + 观众剧评」,拿不到正片。广告解锁模式在 App 里,与网页无关;网页本身没有解锁环节。

## 补测:登录后的网页版播放(2026-11-07,有头 Playwright,用户本人扫码登录)

用户指出网页版要登录。补测《掌上珠》`/player/7561390625552092222`,持久化浏览器配置,用户用红果 App 扫码登录后观察 200 秒:

| 观察 | 结果 |
|---|---|
| 未登录 | 页面里已加载第 1 集完整片源(MSE,`duration = 61.6`),但被「扫码登录」浮层挡住,播不了 |
| 登录后第 1 集 | 正常播完,61.7 秒;画面 720P 正常渲染(截图为凭,不是黑屏) |
| 第 2 集 / 第 3 集 | 能播,时长 76.9 秒 / 96.4 秒 |
| 选集 | **第 1–5 集可播;第 6 集起带锁**(「扫码进入 App 端,免费看全集」) |
| 广告 | 网页上第 1–3 集**没有广告** |
| 每集结束 | 画面换成「扫码进入 App 端,免费看全集」二维码,下一集要点选集(或稍后跳转) |

**含义**:网页版登录后能看到每部剧的**前 5 集**,无广告、不加密到需要破解(普通 Chromium 能直接播)。前几集正是开头钩子与人设立起来的地方,对「为什么爆」最关键。
在控制台里开一个有头浏览器、登录用户自己的账号、正常播放并录下画面(屏幕录制),不碰签名与解密;第 6 集以后只在 App 里,走手机录屏或标「需人工获取」。
注意:逐集页 `/player/*/*` 是 robots 禁止爬虫访问的 —— 这里是人登录后在浏览器里正常观看并录屏,不是爬虫批量抓取;频率要按「人看剧」的节奏(一集一集实时播放),不做加速批量。

## 反证(为什么不是别的解释)

- **「10 秒是因为只下了一段?」** 不是:`Content-Length: 1173031`(整个文件 1.17 MB),`ffprobe` 读出 `duration=10.000000`,文件本身就是 10 秒。
- **「网页别的集也许有完整公开 mp4?」** 逐集页 `/player/{剧}/{集}` 被 robots 禁止,本次没去测;第三方工具全都走 App 接口 + 解密,也说明网页上没有完整片源可拿(jackotom 原文:「网页未提供片源时尝试补充取址」)。
- **「广告解锁是不是能绕?」** 网页没有广告解锁环节;解锁在 App 里,与本问题无关。绕过它同样属于规避权利人的措施,不做。

## 对设计的影响(参考库子项目 1)

1. **红果适配器做「元数据 + 剧评」**:每日抓 4 个榜单 + sitemap 里的详情页(限速、遵守 robots),存热度时间序列 → 「热度监控」;关键词检索在本地元数据里做,不碰 `/query/`。
2. **剧评是高价值分析原料**:观众剧评里往往有整剧情节梳理与「为什么上头」,足够 LLM 拆出钩子 / 反转 / 人设 / 爽点(引用要逐字核对)。
3. **正片**:红果不能自动拿 → 控制台标「需人工获取」+ 投递口;人用正常途径拿到的视频(例如自己录屏)放进来,后面转写 / 抽帧 / 拆解照样自动跑。
   10 秒预览可以自动拿,用来看开头钩子和画风(用不用由用户定:`controlsList="nodownload"` 表明站方不希望被下载,虽然它不是加密措施)。
4. **不做**:签名伪造、设备标识伪造、CENC 解密、广告解锁绕过(规避技术措施,《著作权法》第 49 条;第 50 条的例外不含商业创作)。
