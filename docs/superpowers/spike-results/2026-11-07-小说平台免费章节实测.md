## 反证

- **「私用区 0 是因为页面没加载出正文?」** 不是:晋江第 1 章 5237 汉字、17K 第 1 章页面自报「本章共3307字」且正文可读(「沪市,青辅监狱。一间普通的办公室内……」)。
- **「七猫的私用区字符是字体加密?」** 不像:只有 7–23 个、正文摘录逐句读得通;番茄那种加密是成段缺字、占 27–38 %。抓取时仍按章统计私用区比例,超阈值(暂定 1 %)就标「疑似加密,不收」。
- **「纵横最新章的干扰字是加密?」** 那是在付费 / 导 App 的截断页里插的,我们不抓这类章节。

## 对设计的影响

1. **小说适配器第一版:晋江、17K、纵横、七猫**,只抓**免费且明文**的章节:每章入库前代码判 —— 私用区比例 ≤ 1 %、没有「去 App / 开通会员 / 订阅」截断标记、正文汉字数 ≥ 本章自报字数的 80 %(有自报时);不过就标「不收」并写原因。
2. **热度**:各家榜单 + 书页的点击 / 阅读 / 推荐 / 月票数,存时间序列;口径各家不同,只在同一平台内比。
3. **节奏**:低频(像人读书,每章间隔数秒)、遵守 robots、UA 写明身份;遇到验证码 / 风控就停下报错,不重试硬冲。
4. **不做**:付费章、App 专享章、番茄字体反解、起点验证码、盗版镜像站。
5. 用途照旧只做分析:库里长期留拆解卡,原文按策略清理;原创度闸门(子项目 2)拦雷同。
