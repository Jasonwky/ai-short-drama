# 多角色同框:业界常规做法调研(2026-10-19)

- **问题**:首帧要放的参考图超过 Qwen-Image-Edit 的 3 个图槽(3 角色 + 场景)时怎么办。用户要求先查常规做法再动手
- **范围(有界)**:4 个方向 —— Qwen 社区怎么突破 3 张;多角色一致性的通用手段(LoRA / 分区 / 局部重绘);
  其他模型的多参考上限;AI 短剧 / 漫剧实际管线。8 次搜索 + 2 份官方模型卡,查完即停
- **证据等级**:C(官方模型卡 + 教程 / 工作流页面 / 论坛;**没有找到任何来源量化过「同一画面多角色」的一致性**)

## 结论

1. **3 张是模型本身的设计上限,不是 ComfyUI 的限制**。Qwen-Image-Edit-2509 官方模型卡:多图能力是「via image concatenation」训练出来的,
   「Optimal performance is currently achieved with 1 to 3 input images」;2511 模型卡强调的多人一致性是「fusion of **two** separate person images
   into a coherent group shot」。社区里**没有**可信的 >3 张自定义节点;硬塞第 4 张属于训练分布外
2. **常规做法有四类**(按离本项目的距离排):
   | 做法 | 业界怎么用 | 对本项目 |
   |---|---|---|
   | **控制在 3 张内 + 拼图** | Stable Diffusion Art 的 Qwen 双角色教程:`Image Stitch` 左右拼一张 + `Scale to Total Pixels` | 我们实测 1/3:拼在一起的两人**串衣服** |
   | **先出整体构图,再逐个角色局部重绘** | SDXL 时代的主流多角色管线:区域提示词出全图 → YOLO / ArcFace 找到每个人 → 逐人 Detailer / Inpaint(带各自 LoRA 或提示词) | 与我们的「两遍合成」同一思路;我们实测两遍 3/3 |
   | **每个角色训练 LoRA** | 被普遍认为是「最稳的一致性手段」;短剧流程里「训练角色 LoRA → 出分镜静帧」是常见一步;多角色要配合分区隔离(每个 LoRA 只作用于自己的框) | 每角色训练 30–60 分钟 + 显存 / 磁盘;云机盘只剩约 6 GB;多 LoRA 同框还需要分区节点 —— 重 |
   | **换多参考上限更大的模型** | Seedream 4.0(约 6 张,来源不一)、Vidu Q1 参考生视频(最多 7 张)、可灵多图参考(上限未公开) | 都是闭源云端 API,**数据外发**,与「离线优先」冲突 |
3. **AI 短剧 / 漫剧里多人同框是公认难点**:有基于扣子的短剧工作流直接写明「暂不支持多人对话」;创作者反馈「局部重新生成、元素锁定」仍是需求而非成熟功能
4. **对本项目最贴近常规、又不违反离线约束的,是「先整体、再逐人替换」**:两遍合成就是它在 Qwen 编辑模型上的形态。
   常规版本多一步「**只在那个人的区域里改**」(检测框 / 掩码 + 局部重绘),我们的设计是整图编辑、靠提示词说「只换这个人」—— 区别在于
   第二遍会不会动到别的地方(实验里 1/3 背景多出一个人,可能就是整图重画的副作用)

## 反证与局限

- 「LoRA 最稳」来自教程和论坛的共识,不是量化对比;对 Qwen 2511 这种编辑模型,定妆图参考 + LoRA 哪个更稳没有数据
- 闭源模型的参考张数各来源说法冲突(Seedream 6 / 12、Nano Banana 单图 / 8 张),没有逐个去官方文档核实 —— 反正不能用(数据外发)
- 局部重绘版本(带掩码)在 Qwen 编辑模型上没有现成的官方工作流;要做得自己拼(人物检测 → 裁剪 → 编辑 → 贴回)
